# 复盘

我们之前已经说过，用复盘来分析观众的反应，是一种提高你商业感知力的方式。然而，你在每场表演后进行复盘，其实还有别的目的。你可以用它来回顾一下表演中出现的错误、问题，或者意想不到的困难等等，是否是你的错，还是观众的问题，或者只是单纯的运气不好。

任何时候，出现这种情况，你都必须做下面两件事之一。可以重新编排效果，确保问题不会再次发生。例如，如果观众在放回所选牌的时候，出现了麻烦，那可以让他用瞥一张牌的方式来记住一张牌，而不把它从牌叠里拿出来。这样的话，所有的牌在任何时候，都完全处于你的掌控之下。或者，你可以想出一套方法，防止同样的问题再次发生。无论如何，一定要确保这次发生的问题，不会在下次继续发生。就像查克·贝里[^1]曾经说的“别让同一只狗咬你两次。”

这也将我们引向达尔文的法则之一：当你进行实战表演的时候，如果一个问题之前发生过，那么之后还会发生。不管是多么奇怪或者是不可能的事情，只要它成为了你表演中的问题，那么迟早会再次发生，除非你采取措施，杜绝此类情况。而这又将我们引向了达尔文的另一法则：别想着碰运气。

[^1]: 查克·贝里（Chuck Berry）美国歌手，词曲作者，以及摇滚音乐的先驱之一。
