# 演砸了

最近，我和一位搞千术的朋友聊了聊。在谈话的过程中他说，“只要你能找到一个声称自己从来没被抓过现行的老千，我就能让你认识一下从没出过千的人。”同样我会说，“只要你能找到一个声称自己从没演砸过的魔术师，我就能让你认识一下从不表演魔术的魔术师。”

无论你的准备多么充分，依旧有失误的可能。你还是会把魔术演砸。因为你不知道接下来会发生什么，所以最好提前为这种情况做好准备。

很多魔术资料中，都会讲解“退路”的作用。其中多数都说，一个好的魔术师，应该总能让魔术成功，不管发生什么样的情况。这一点恕我不敢苟同。如果你对自己的表演内容非常熟悉，那么即使发生失误的时候，也能进行救场。如果可以的话，你一定要这样做。然而，有时你却不得不放弃一个魔术。对观众而言，没什么比看着魔术师不顾一切手忙脚乱的去救场更尴尬的事情了。你必须知道，何时才能救场。如果实在没法救场，不如简短地和观众道个歉，然后继续下一个魔术。

当一个魔术演砸的时候，你也会心情不好。自然会倾向于，将这种负面情绪传递给观众。你想继续说自己有多么的抱歉。你想告诉他们，你也不知道为什么会发生这样的事情。你想跟观众解释，这之前从未发生过。你想给出很多理由，证明这不是你的错；只是因为太潮湿了，牌太旧了，以及你正在经历一场感情危机。

你想通过这一切来让自己好受一些。但是你的工作不是让自己好受的；而是让观众好受。告诉他们这些事情，只会让他们更不好受。首先，他们并不关心这样的事情之前是否发生过，也不关心道具商是不是卖给了你一个山寨的折币道具。他们来看表演是放松心情的，而不是听你倒苦水。其次，你的这种行为会让他们感觉很尴尬。看到别人受苦，自己也很难受，特别是当某人沉浸在他的不幸情绪中时。

所以当表演出问题的时候，你的工作就是尽快让观众忘掉它。自怨自艾只会让观众记住你确实搞砸了表演。如果你不把这当作一回事儿，那么他们也会不以为然。

微笑（即使你心里在哭），然后轻描淡写的说一句，“抱歉各位，这个魔术不太理想，我再演点别的好了，下一个大家肯定会喜欢的。”接着继续下一个表演，别再提这个事儿。记住，观众对于这件事的态度以及反应，完全取决于你。

那么如果你把整场表演的最后一个魔术搞糟了怎么办？而且没有下一个魔术可以继续。这时候就要大开脑洞了。一定要准备一个可以应急的效果，好在紧急时刻能够拿来救场。你最后表演的东西，往往是观众印象最深刻的。基于这个原因，最后一个魔术绝对不能搞砸。

那么如果收场魔术和救场魔术都搞砸了怎么办？如果是这样的话，那就请重新读一遍练习与彩排这个章节吧。
