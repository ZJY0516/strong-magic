# 意外使人分心的事情

在控制注意力的章节，我们已经讨论过减少让观众分心的事情是多么必要。然而，并不是所有让人分心的事情，都能处在你的控制之下。比如房间的后门，可能会突然砰的一声关上。下一桌的观众可能会突然放声大笑。一位观众可能会打翻他的酒杯。

如果遇到此类情况，你就必须使用自己的注意力，来控制观众的注意力了。如果可以无视让人分心的事情，那就无视它好了。记住，你看哪里，观众就看哪里；你觉得重要的东西，他们也会觉得重要。如果你因为某件事情分散了自己的注意力，那么就相当于允许观众也可以这么做。

如果某些让人分心的事情实在无法忽视，那就尽可能让它的影响最小化，然后迅速回到你的效果当中。你绝对不能让自己因为某件事而分心。因搞笑的评论而承认分心与你让自己被打乱了阵脚而不知所措，绝对是有着天壤之别的。

这便是事前准备交给我们的东西。当你的技巧和台词都协调完美的时候，没有什么能够打断你。你的大脑可以自由地处理各种意料之外的突发情况，然后将观众带回表演当中。最重要的一点是，你必须时刻让自己掌控当下情况。
