# 练习与彩排

军方知道，想要掌控无法预料的情况，关键在于进行合适的训练。同样，你也必须正确的训练你自己。有时，你会在表演中出现技术性失误。有时你需要改变台词，来适应一些意料之外的情况。有时你需要随机应变，处理一些由观众引发的问题。

你必须将自己的技巧磨练到完美，直到在表演时可以不为此分神，好将全部的精力都放在修改你的台词，以应对各种意想不到的情况上。你必须将自己的台词烂熟于心，张口即来，这样如果需要的话，才能让大脑专注于解决一些技术上可能带来的麻烦。你必须让技巧和台词都得心应手，让它们两者进入一种类似于汽车的“自动驾驶”状态，好让你的大脑能够抽出空来，处理一个麻烦的观众，或者是一些意料之外的会让人分心的东西。

想要实现这一切，靠的就是练习和彩排。像尤金·伯格，T.A. 沃特斯以及其他魔术作家，都强调过练习与彩排间的区别，但这里我还想再啰嗦一遍：练习是为了精进手法，彩排则是为了精进表演。

## 练习

练习是要专心的重复一个固定的手法。既要在镜子前练习，时刻观察动作是否准确。也要脱离镜子练习，避免依赖镜子的反馈。

我不想给大家一种，练习就是机械重复某个动作的印象。练习应该既是分析，也是创造的过程。然而无论如何，重复也是必要的。我们现在讨论更多的就是这个方面。重复练习一个动作，能让你在实际表演的时候毫不费力，也无需思考。

实际上，练习就是一种调整的过程。这与训练士兵格斗很相似，我们要训练他在无意识的情况下，做出正确的反应，比如在压力很大的战场上。表演虽说应该是一个享受的过程，但其实也将你置于某种压力之下。你通过自我调整，就能在合适的时机自动的做出某个动作，而避免因为思考而产生的额外压力。

我发现这一技巧非常奏效。如果我总要在一个特别的魔术中说出某句台词，那么在练习的时候，我也会每做一次相应的动作，就背一遍这句台词。我不用担心这句台词的语调是否到位之类的问题，只要集中精力，将台词与动作协调起来，换句话说，就是把握好动作与台词发生的时机。如果我在两个不同的魔术中，都要用到同一个动作，那么练习的时候，就会抽出一半的时间来说第一种台词，而用另一半时间说第二种。

起初你可能会感到害羞。其实不用急着否认，如果任何人在听你讲话的话，那么你听起来一定很傻，毕竟你要像鹦鹉学舌一般，一遍遍的机械重复一句话。所以只要在没人的时候练习就好了。你会发现这个技巧能让你的表演更加流畅。你还会发现，这能帮你在表演到一半的时候，不会晕头转向。台词会提醒你下一个动作是什么，而每个动作又会提醒你下一句该说什么台词。

## 彩排

如果说练习只是重复表演一小部分的话，那么彩排就要将你的整个魔术，从开头到结尾完整的进行一遍。事实上，如果你有一套表演的话，就必须从头到尾都来一遍，而且中间不能停。你要演好每一个动作，就像正式表演中一样。你要说出每一句计划在实际表演中讲述的台词。你还要像实际表演中那样，去操作你的每一件道具。

如果你打算在表演一个魔术的时候，让观众在牌上签名，那就真的要把笔拿出来，像默剧演员那样，把笔递给某人。留出合适的时间，给你的“幽灵观众”签名用。还要有意识地和你想象出来的观众进行眼神交流。在私下彩排的时候，你要像一位演员那样，不为这些行为而感到害羞。

你必须彩排到做梦都能背出台词的程度才行。当然，这并不是说让你像睡着了那样去说台词。而是意味着在关键时刻，你不用将注意力集中在台词上面，而是可以想想下一步要怎么做。

你可能觉得自己神思敏捷，在表演的时候知道该说什么。但如果你不小心搞丢了观众的牌，大脑就要一边想着如何找到它，一边又要强迫自己妙语连珠了。所以最好的方法是提前编排好你的台词，然后把这件事情交给记忆去完成。

许多魔术师还有一个误区，认为练习和彩排是你把一个流程变完美之前才应该做的事情。但其实它们是一个不断发展的过程。即使你已经做到了完美，依旧需要练习和彩排。

这主要有两个原因。首先，你会惊讶于已经掌握的动作和效果居然还有上升的空间。其次，即使你不停地表演，也无法保证动作或者表演可以持续精进。半小时的时间，可以让你练习一个动作很多次，但也许你一年才能用上一回，即使你的表演真的非常多。所以如果你不经常回顾这些内容的话，水平依旧会下降。

你练习和彩排的时间，确实应该多花在那些你已经掌握并且早已投入实战中的内容。而研究新内容，则应该放在你基本练习之后的闲暇时间里。
