# 思考影响风格

既然风格应该是一件很私人的事情——你的魔术最私人的方面——引导你开发你风格的原因应该是对你最重要的原则。然而，有一些原则要记在心里。首先，风格应该是你表演角色的延伸。因此，对风格的选择应该与你的角色相一致。你的角色更像是用 overhand shuffle 还是 riffle shuffle 的人？

风格同样应该支持内容。达希尔·哈米特[^1]的强硬的写作风格与梦幻国度的主题是不相符的就像用克拉克·史密斯[^2]的很华丽的风格写侦探小说一样。（没错，文学中一种经典的讽刺就是用一位作家的风格去写一些完全不相符的内容。结果总是幽默的。）

同样的，你的风格应该与你选择的要表演的效果相符。效果与你呈现它的方式应该交相呼应，而不是相互摩擦。因为你所表演的效果同时还要符合你的角色，所以你的风格应该和你所表演的效果和你的角色都能很好的兼容。

最后，之前我们的讨论的例子已经展示了风格和方法怎样在一个效果之中互相影响。我们讨论了让观众选一张牌的方法，是将牌在手上展开让观众拿一张，将牌展开在桌面上，或是让观众偷看一张。你选择的方法或许是由你想要怎样去控制那张牌所决定的。然而，你用哪一种控牌的方法或许是站在风格的角度上，你让观众选牌的方法所决定的。

你越是有个人风格，你可以用的手法和方法就有更多的要求和局限。这就是那句名言一个方法适用于一位表演者并不意味着它适用于其他的表演者背后的真理。它同样证明了以下这句话的不成立：一个方法实际上等于另一个或是最简单的方法永远是最好的。

[^1]: 达希尔·哈米特（Dashiell Hammett），美国侦探小说家。生于马里兰州圣玛丽镇。引领“美国革命”的巨匠，硬汉派小说鼻祖，“黑色电影”的创始人。

[^2]: 克拉克·史密斯（Clark Ashton Smith），美国诗人、作家。
