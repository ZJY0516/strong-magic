# 将风格作为一种意识行为

一些人可能觉得上述的联系是完全没有必要的。一种普通的理论是艺术家的风格是一种只与时间有关的某种东西——它会随着时间的流逝自然地形成。艺术家越是成功，他就越有可能形成他的风格。

海明威（Ernest Hemingway）是近现代的文学巨匠。他那异常清晰节俭的写作风格显得异常简单使得观众认为这是他先天的表达方式，或许是因为有限的教育程度或是有限的词汇量。实际上，文学学者知道海明威为了他简单而淳朴的经典风格做出了很多的努力。

据说法国作家居斯塔夫·福楼拜[^1]每次都尽量避免两个相同的单词出现在同一张纸上。你可以确定这种风格对福楼拜来说是要下很大的功夫的。在每一种艺术之中你会发现公众认为自然发生的事情其实是经过了大量的思考和下了很大的功夫才达到的。

思考一下魔术中的一个例子。瑞恩·拉凡得曾经写道，“我花了三个月，并不仅仅是为了创造一个流程，而是为流程的高潮找到合适的用词，并且又用了三个月试着找到每一个字正确的发音和语气。”这听起来像是某人的风格是无意识之间形成的么？

我认为Slydini和哈利·罗瑞恩是很棒的魔术师，就像海明威是很棒的主流小说作家，罗德·萨尼（Lord Dunsany），克拉克·阿什顿·史密斯（Clark Ashton Smith）和雷蒙·钱德勒[^2]是很棒的类型小说作家。这两位魔术师的风格都不是偶然的产物。

Slydini高度精密并且善于分析的魔术理论是众人皆知的。哈里·洛拉尼，有一种更加自然的风格，更加像是一位天生的表演者。然而，任何和洛拉尼讨论过魔术的人都知道他对好魔术有着非常坚定的信念——来自于他丰富的经验和大量的思考。这些信念很好地折射出他的风格。

我这样说好了。或许随着时间的流逝你在并没有经过大量的思考和付出的情况之下形成了你的个人风格，但你的风格是否一定会感染你的观众并增强你的魔术，就很难说了。

这并不意味着表演之中每一个效果的无数个十字路口的每一个选择都要经过缜密的思考。在一位真正的艺术家的表演之中，有很大一部分选择是有意识的，比大多数魔术师猜想的要多。然而，随着你的风格越来越犀利你会有一种本能自动帮助你在很多十字路口处做出选择。

举个例子，作为对之前讨论的补充，另一个在我的魔术中扮演重要角色的理论是动作最简化。在斯特伦克（Strunk）和崴特（White）的书《风格的基本要素（The Elements of Style）》中建议到，“省略没必要的话。”我觉得这句话只要重新措辞对魔术也适用，“省略没必要的动作。”这时当我研究一个新的效果时我会不自主地选择多余动作最少的方法。我已经不需要在每一个点上展开细致的分析。然而，之前对于其他效果，手法和方法的分析帮助我形成了那种直觉。

[^1]: 居斯塔夫·福楼拜（Gustav Flaubert），1821年12月21日出生于法国卢昂一个传统医生家庭。福楼拜的成就主要表现在对19世纪法国社会风俗人情进行真实细致描写记录的同时，超时代、超意识地对现代小说审美趋向进行探索。

[^2]: 雷蒙·钱德勒（Raymond Chandler），推理小说作家。他对现代推理小说有深远的影响，尤其是他的写作风格和看法，在过去60年间为相当多的同行所采用。钱德勒的主角，菲力普·马罗，成了传统冷硬派私家侦探的同义词，与达许·汉密特的山姆·史培达并驾齐驱。
