# 风格中的自然元素

在讨论魔术中的风格的最后我一定要提到的是魔术师在讨论风格是总是要提到的话题。就是你常会听到某人很严肃地说，“重要的是自然。”他们总是发表这样的一件好像讨论应该以此结尾一样。

自然是风格中重要的一方面是一句很深刻的话。但它并不是我们讨论的结尾，它应该是另一场讨论的开始。这是因为对自然地赞美只会引起另一个棘手的问题：什么是自然。我们应该怎样判断一个手法或是动作是自然的？

一些魔术师认为这一问题应该由投票决定。再一次对话中，一位魔术师会说，“我并不认为它看起来是自然的。”另一位会说，“我觉得它是。”每个人都说出自己的意见并且人数多的获胜。

很多其他的魔术师认为自然就是将自己加装成是一位普通观众。他们会说，“这是不自然的，没有一位普通观众会这样做。”一个问题是通常来说近景魔术，并且尤其是纸牌魔术，需要你表演一些普通观众从不会去做的事情。因此，普通观众的做法在决定什么是自然这一问题时的帮助是很有限的。

更重要的一个问题是大多数魔术师并不理解自然风格和自然的风格这二者之间的区别。戴·弗农使得自然的风格在近景魔术中流行起来。我说的自然的风格是指一种模仿自然的风格，在上述例子中指的是模仿普通观众做事的方法。

这一风格会提供特定的好处。然而，魔术中其他的大师——阿斯卡尼奥和沙丁尼随便说两位——他们用完全不同的方法却取得了相同的成功。他们的风格与自然完全不沾边。这就意味着，他们运用道具的方式和普通观众完全不一样。然而，他们没有一个动作是不自然的。如果是的话，他们的魔术不会有那么大的威力。

这就意味着在一位普通观众会怎样做之外存在着另外的检验自然的法则。并且没错，的确有。人们判断某事看起来自然与否是基于本能。通常人们不能告诉你为什么某物看起来不自然。（没错，这就是我之前提到的人们对这一问题的意识混乱的根本原因。）但是观众无法告诉你他觉得某事不自然的原因并不意味他没有原因。

我认为人们在判断自然时有两个法则。第一是动机。任何时候你做任何动作，不论这一动作多小，如果你没有做它的原因的话，一个立即对每一位观众都很明显的原因的话，这一动作就会显得不自然。没有什么比无动机的动作对观众来说更可疑的了。

当然，在一个效果之中你做的大多数的动作都有一个很好的原因。但是通常这一原因是与方法有关的，你必须做这一动作否则魔术不会成功。因为观众不能（至少不应该）意识到方法的存在，这一动机不足以使得这一动作显得自然。

不论你做某事的真正原因是什么，在观众看来这一动作必须有一个和效果（方法的反面）相连接的好的原因。否则的话，这一动作会看起来不自然。就像一位好的演员一样，你应该时常问你自己，“此刻我的动机是什么？”

另一个检验自然的法则是动作最简化。人们在本能上觉得做一件事的自然的方法是消耗最少能量的方法。这就是为什么你可以表演一个观众从未见过的动作但他们仍然觉得它是自然的的原因。

一个很好地例子是在任何一个赌场二十一点的桌子上。人们看到荷官以一种他们自己从没做过并且从没见过的方式洗牌，切牌和发牌，处理筹码。但是没有人觉得这些动作是不自然的。这些动作看起来都是自然的因为很明显它们是做这些事情最有效率的方法。人们感觉到如果他们自己做这些事情千万次之后这就是他们自己做这些事的方法并且它是完成这些事最简洁的方法。

这就是为什么在魔术中一些看起来最不自然的动作发生在当一位不玩牌的普通观众被要求洗牌，切牌，发牌或是用牌做一些其他的动作。他并不常做这些事情所以他并没有一个做这些事情的自然的方法，一种避免浪费动作的方法。

这就是判断自然的两个法则。第一个是自然并不一定是自然的。为了让你效果中的必要动作显得自然你必须花费大量的时间思考，总是应用动机和动作最简化这两个法则。

第二是自然风格只是一种可行的方法。作为一位艺术家，你必须决定它是否是你想要的风格。然而，风格之中的自然的元素并不仅仅是一个选项。如果你想要避免表演之中引起观众怀疑的话它是你的必选项。并且避免怀疑要比怀疑已经产生之后设法消除要简单的多。
