# 结构

为了出色的完成这项工作，你的开场效果要像其他的每个效果那样，应该是比较强的一个。但也不能太强。事实上，它应该是整个表演中相对最弱的一个。

在讨论单个效果的影响时，我引用了考尔斯·斯特里克兰的话，“（开场）之后的效果，必须比之前的看上去更重要、更有趣⋯⋯即使你能让后面的效果都（与开场效果）保持在同一个吸引观众兴趣的水平上，他们也不会满意的。”这条规律适用于整个表演，同样也适合表演中每一个独立的魔术。

在《魔术与演技：魔术师手册》[^1]这本书中，亨宁·内尔姆斯谈到了“兴趣曲线”[^2]的概念。利用这个概念，能让我们每时每刻都把观众兴趣的增减图像化。这是一种思考相关概念的有效方式。合理的表演结构，就意味着你能让观众的兴趣曲线，从开始到结束一直处于上升的状态。

正如内尔姆斯所言，兴趣曲线对于一个独立的效果来说，就像一条在最后才到达高峰的波浪线。因此，你想通过一系列的效果，让观众的兴趣曲线平稳上升，这是不太可能的。它们只可能是一系列的波浪线。但是——也是最重要的是——在一场出色的表演中，必须让每条波浪线的最高点，都比它前一条波浪线的最高点还要高才行。如果你画一条线，把所有波浪线的最高点都连起来，那么这条线便会组成一条平稳上升的曲线。

有些效果有不止一个高潮。正如我们之前所见，在这样的情况下，之后的高潮都要比前一个强，这样兴趣曲线才能保持在整个效果中都稳步上升的状态，我们也才能避免出现致命的反高潮。当一个多高潮的魔术出现在一场表演中时，那么它的第一个高潮，就要比前一个魔术最后的高潮还要强。而它最后的一个高潮，仍然要比下一个魔术的首个高潮弱才行。只要记住，把表演中所有高潮产生的点连起来，总是一条上升的直线就行。任何向下的倾斜都是致命的。

这就意味着，当你想把几个魔术组合成一个表演的时候，必须将它们的效果按照从最弱到最强进行排列。每一个都要比前一个更加不可能（不可思议）才行。是的，我知道从逻辑上讲，“可能”和“不可能”，或者说这个比那个更加“不可能”是很难判断的。这个道理虽然从逻辑上说得通，但是从情感上是说不通的。从直觉上讲，我们都能分辨出有些效果确实比另一些更加不可思议。在魔术中，不可思议的程度一般由观众对你的信服程度以及效果的作用范围来决定。（让一整副牌变色，就要比只让一副牌中的一张变色更加不可思议。）

在节目单中加入各种类型的效果，会让你体验到它们之间强弱的不同。这样便很容易选出几个效果，并把它们按照强度递增的顺序进行排列和表演。在实际操作时，你还会遇到很多问题。一个纸牌魔术可能会为另一个魔术完美地提前做好准备。但不幸的是，第一个效果要比第二个强。另一个纸牌魔术也许是所有魔术中最强的，但它需要提前做好准备，所以把它作为开场可能会更加容易。

编排好各种各样的效果，并让它们的影响力不断上升，这是需要创造力的：这意味着你要解决数不清的实际问题。像往常一样，你依旧需要决定到底是选择最容易的方式，还是最有效的方式来达到这个目的。

我曾经听说一些魔术师主张，最好的编排表演的方式便是“有高潮也有低谷”。他们提倡将效果强和效果弱的魔术，多多少少的随机混在一起。但这样的编排模式有个问题，当你到达低谷的时候，观众并不知道接下来还会有高潮。他们或许认为你表演的高潮部分已经过去了，而接下来只会走“下坡路”。因此，即使他们没有马上就走，也会开始失去兴趣。相信我，一旦观众对你失去了兴趣，想要再次挽回他们就非常难了。

所有戏剧表演的基本准则之一，都是后面发生的事要比前面的更有吸引力。你会发现，它在戏剧、演讲以及编剧中都有所体现。而且，每个职业魔术师都会从自己的艰苦经历中发现它。还是把什么“有高潮也有低谷”这样的概念，留给那些不表演的人吧。如果你想让自己的表演获得最大的影响力，唯一的方式就是编排，编排，再编排。

[^1]: 《魔术与演技：魔术师手册》（Magic and Showmanship: A Handbook for Conjurers）。
[^2]: 兴趣曲线：Interest Curve。
