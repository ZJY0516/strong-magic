# 结尾效果

现在你该明白，为什么结尾的效果，必须是整场表演中最强的了吧。你要用结尾的效果来引发观众最热烈的掌声。我发现有两种类型的效果特别合适。第一种是集合了许多悬念的魔术。悬念能在观众中制造压力。当你将压力积累到极限，再以一个强烈的高潮来释放它，便会在最后得到观众最热烈的掌声。

另一种特别适合放在结尾的效果，便是具有多重高潮的魔术。如果这个魔术的高潮比之前任何魔术都要强，然后你还能在这个基础上，继续快速叠加一两个高潮，每个都比前一个还要强，那么你便能在表演结束时，创造一条急速上升的兴趣曲线，这样观众也会给出最强烈的反应。

我还发现，如果你在表演最后一个魔术之前，就告诉观众这是我们最后的表演了，也会很有用。只要说上一句，“让我给大家表演最后一个吧。”或者“最后的这个魔术，我需要你的帮助。”这能提醒观众，如果他们之前还在犹豫是否鼓掌的话，那么接下来便是时候了。他们应该表示对你的欣赏和感谢，不仅仅只是为了最后这个特别的魔术，而是为了你的整场表演。
