# 第十一章 『编排』

合理编排表演的重要性，可能仅次于塑造角色，正是它决定了你的魔术，究竟能对观众产生多大的影响力。就好比既有像艾伯特·戈什曼这样“一招鲜，吃遍天”的职业表演者，同时还有需要好几套表演才能勉强度日的魔术师。就我而言，便有七套不同的近景纸牌魔术，以及一套时长为一小时的揭秘千术表演。但你究竟需要多少成型的表演，还是取决于两点：一是你所处的环境和表演的频率；二是你的个人喜好。

其实，就算只用我现在一半的材料，我也完全应付得来；只不过有八套不同的表演，于我而言就足够了，它们既能满足我对表演多样性的要求，又能将我对魔术的兴趣维持在最高点。幸运的是，虽然我并不是真的需要八套表演，但依旧可以常常充分发挥它们的作用。

就算你从不做专业的表演，依旧会发现，如果把自己节目单里的素材进行预先编排，绝对是很有价值的。即使你能在即兴表演中，依靠临时起意来增减或者替换一些效果，也依旧要根据表演来考量你的素材，只有这样才能让非正式的表演也有自己的结构。

此外，对编排表演的原理有一个清晰的认识，也能让你在完全即兴的情况下，“凭感觉”就可以构想出一场有效的表演。即使只是在朋友面前随便露两手，如果能够按照适当的编排原理来选择魔术的话，也会让你的表演更加精彩。

有一句关于演讲的箴言如是说：你的第一句话和最后一句话，往往是最重要的。第一句决定了观众是否愿意劳神费力的听完你剩下的内容。而最后一句，决定了他们是否会记住你。同样的道理，魔术也适用。在一场魔术表演中，最重要的便是你开场和结尾的效果。
