# 调和角色和日常的生活

最后，如果你不靠魔术吃饭的话，在塑造角色时你还有最后一个因素要去考虑：你舞台之上的个性与你舞台之下的个性的区别。当约翰·汤普森在舞台上的时候，他是强大的汤姆森，一位愚蠢而又无能的魔术师。但在他的私生活中，他不必保持这种个性，因为他的观众并不会一直呆在他的身边。

但是，如果你不是专业的魔术师的话，你的朋友和亲属也会是你的魔术观众。如果你的表演个性与你平日里的个性完全不一致的话，在他们的眼中这也没有什么可信度。这就是为什么你的个性应该从你真实的个性之中提炼出来。在塑造这个个性的时候，你需要强调你性格之中的某些元素并且淡化其它的元素。但只要这些元素来自于你真实的个性之中即使是最了解你的人也不会觉得有问题。
