# 魔术师与“共识现实”

我清楚地记得，当我还是个少年的时候，第一次去坦嫩魔术商店[^1]时看到的一个纸牌效果。一位观众从发在桌上一排的六张牌中，随便选择了一张，然后表演者展示他成功预言出了观众的所选牌。我就是那位选牌的观众。

表演者让我从 1~6 之间说一个数字。我选了 6。然后他拼写了“Six”这个单词，每拼一个字母就点一张牌，然后把第三张推向我。“太不思议了，”我心里想。“他怎么知道其实我说‘six’是想要第三张牌？当然了，如果我真的想要第六张，我会说‘e-l-e-v-e-n.’”

“共识现实”是一些政治学家使用的术语，指的是每种文化都认可的信仰。因为在文化之内，没有人会质疑这种被当作现实的信仰，即使它可能根本无法反映客观现实。所以一个人的信仰就永远无法被接受考验：相反，他们的信仰还会因为一直接触到怀有同样信仰的人而得到巩固和加强。“共识现实”，其实就是一种共同的精神疾病。

魔术爱好者的世界，便是一个由“共识现实”支配的地方。在这个理想世界中，即使两张牌分得再开，也会被当作是一张，而且四张牌的厚度和一张没有任何区别。同样，他们都相信，如果你用印度洗牌法洗牌，让观众喊停之后再把底牌展示给他看，观众也会相信自己做出的是一个自由的选择。

[^1]: 坦嫩魔术商店（Tannen's Magic Shop），位于纽约市先驱广场区的一家魔术店，由 Louis Tannen 创立。
