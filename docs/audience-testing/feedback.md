# 反馈

形成“商业意识”的关键，便是从观众的反应中学习。为了从观众的反应中学习，首先你必须留心观众的反应。其次，必须合理的解读其中的含义。

第一步，留心观众在某些方面的反应，虽然看似简单，但其实多数的魔术师都做不到。记得有一次，我和一个魔术师一起坐在酒吧里。他开始跟我谈起表演弗农的“骗了胡迪尼的魔术”[^1]是多么的“有趣”。这是一个用双背牌表演的“有雄心的扑克”效果。因为这个版本较纯手法版相比，并没有任何优势，所以我表现出了一些惊讶。接着，他提出向我展示一下这个很强的魔术。

他以一个业余魔术师的架势，转身对着坐在他身旁的一对陌生男女，闯入他们的对话之后，拿出一副牌，开始表演魔术。他让女观众选了一张牌。然后他把牌放在了顶牌（双背牌）下面，接着做了个双翻，展示她的牌跳到了牌叠顶部。女观众反应很不错。然而，当他重复这个过程的时候，女观众指着双背牌，要求看看它究竟是什么。（很可能她并没有怀疑这是一张双背牌，只是猜想它可能是自己所选牌的复制品。）

魔术师用一些模棱两可的话，将她的这个请求搪塞了过去，并且继续表演。但是从那一刻开始，女观众就完全失去了对这个效果的兴趣。她绷着脸，几乎没太在意之后的表演。当他终于结束的时候，女观众没有做任何评价，而是继续转过脸去和她的同伴聊天。我本以为这时候他会跟我解释为什么表演如此失败。但是没想到，他得意地笑着对我说，“你看，这招是不是每次都能秒杀观众！”

直到今天，这件事依旧让我很困惑。为什么他没有发现，在自己拒绝了观众看顶牌的要求之后，她就已经在忍受他的表演，而且脸上写满了无聊的这个事实呢？也许是因为他太享受这个表演的过程，而没有注意到别人没在“享受”吧。

事实上，许多魔术师表演似乎只是为了取悦自己。他们可能并没有注意到自己的观众已经起身，并且走了一半。还有许多魔术师不得不专注于效果的技术部分，从而无法腾出注意力来留心观众。这两种情况，都是魔术师太过于专注自己正在做的事，而没有留心观众的反应。

因此，想要形成“商业意识”的第一步，便是磨练好你的技巧和演技，这样才能在表演时最大程度的忽视它们，从而将注意力放在观众身上，而不是你正在做的事情上。

还有很多方法，也能让你对观众的反应更加敏感。我强烈建议大家阅读一下关于非语言交流方面的书，也就是肢体语言。这能帮你从观众身上捕捉到一些细小的、下意识的线索。（尤其建议多数魔术师记住表示“无聊”的那些非语言信号。）

我还建议大家要特别留意一下观众的眼睛。没什么比眼睛更能反映出一个人的所思所想了。如果你对观众的眼神足够敏感，那么只要他往某个方向一瞥，你就知道他在想什么。（当然，你的眼神也会告诉别人你在想什么，这也是为什么表演者的眼神在错误引导中扮演着重要角色的原因。）观众的眼睛会告诉你，他们是真的被刚才的表演骗到，还是心存疑问，但嘴上没说。

[^1]: 骗了胡迪尼的魔术（Trick that Fooled Houdini）。
