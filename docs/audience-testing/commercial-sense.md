# 商业意识

似乎你只有在真正的普通观众面前竭尽所能的去尝试，并将这些理论上的东西抛之脑后，才能知道究竟选择什么效果才可以发挥出它们的作用。你还得有足够多的时间留给表演，准备表演所用的新素材，以及很多接触观众的机会，好像这才是我们要的答案。

当然，我们中没有任何人，甚至是职业表演者，都没有时间用每个魔术对观众进行测试，从而找出最合适我们的一个。当你买了一本新的魔术书时，也无法把书里的每个魔术都找观众表演一遍，从而决定他们究竟喜欢哪个。

所以，作为一个表演者，必须形成这种非常重要的品质，我称其为“商业意识”。而老千和骗子会把每个欺骗者身上这种善于发现赚钱机会，知道什么骗术最有效，以及如何更好地完成欺骗过程的本能，称之为——“骗子意识”。同理，每个成功的魔术表演者，最终都会形成这样一种本能——他们知道什么效果、方法和表演方式才最适合自己。

一个优秀的百老汇舞台总监，便具有这样一种很强的“商业意识”，他只要独自在剧场里看上一场新剧，就能知道它是否会卖座。长时间的工作，已经让他对大众的喜好了如指掌。这种“商业意识”与你要练就的眼光只有一点不同，你不但要了解观众喜欢什么样的表演，还要了解观众喜欢看你做什么样的表演。因此，作为一个魔术师，你的“商业意识”不但要着眼于观众的喜好，还要着眼于自己本身的优势与劣势。

“商业意识”从很大程度上讲，仅仅是客观现实中的问题。所以你必须把自己对于一个效果的反应与观众对它的反应区分开。但多数魔术师似乎都无法做到这一点（详见古德里夫的例子）。一旦你意识到，喜欢一个效果，并不意味着必须把它加入自己的节目单里，那么你就已经在正确的方向上迈出了一大步。一旦你意识到，一个效果的好坏与它是否能够骗到你并无关系，那么你便又在正确的方向上迈出了一大步。
