# 盲人给盲人指路

这个“共识现实”问题的根源，来自于魔术师要依靠其他魔术师来告诉他们，究竟什么才构成了一个强大的魔术。但事实是，当另一位魔术师告诉你，你刚刚表演的这个魔术是否对普通观众有效的时候，他是按照自己的喜好来进行判断的。所以，我想不用说，你也应该知道这种判断是毫无用处的。

有很多有趣的文献，都是关于人们在面对相反的证据时，是如何运用心理机制来让偏见合理化的。而魔术师们执着于他们预先设想的、关于什么才是构成有效表演的方式，绝对能为这个领域提供一个有趣的研究案例。

在阿尔·可兰的“魔术卡带（Magicssette）”中，可以找到一个很典型的案例。这卷卡带主要由可兰在电视上表演各种效果的音频组成。而且还包含了一段古德里夫的介绍。在这段介绍中，古德里夫[^1]不止一次觉得阿尔·可兰缺少表演技巧。很明显，这个基于古德里夫的评价认为，可兰并不像他所认为的其他心灵师那样夸夸其谈。我个人感觉，其实古德里夫介绍之后的表演部分，才是杰出表演的例证。

然而，我的目的并不是拿自己的观点和古德里夫做对比。重要的是，在这卷卡带中，我们能清楚地听到可兰获得了观众强烈的反响——惊讶的喘息声、掌声、笑声——这些都是给他的。但这一事实，并没有让古德里夫改变他关于什么才是好表演的看法。在古德里夫看来，可兰并不是一位优秀的心灵师，因为他并没有按照自己认可的方式去展示心灵表演，而且观众的反应也是应该受到谴责的。

即使是自己表演能力很强的魔术师，依旧会对“什么成就了好的表演”这个问题抱有偏见。因为问题的关键在于，他们只知道什么办法对自己有用，但常常无法分辨一个差别很大的方法是否对其他人也管用。由此可见：当涉及到表演的时候，别听魔术师的；而要听观众的。甚至连这本书里讲的也别全信——至少，你要有自己的判断。我们要在普通观众面前来测试这些概念，并得出相应的结果。用现在心理学中比较流行的话说，这叫做“现实检验”。如果更多的魔术师也能用现实检验一下他们所理解的表演，那么“共识现实”才能得以终结。

[^1]: 古德里夫（Goodliffe），教堂用品供应商，魔术发明家以及《古德里夫魔术月刊》的编辑。
