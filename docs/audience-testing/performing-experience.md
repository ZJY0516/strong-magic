# 表演经验

如果没有观众的话，就无法进行“观众测试”。这对多数业余魔术师来说，都是一个问题。一般的非职业表演者，无法为自己的表演需求寻找到一个出口。因此，他只能用新魔术来“折磨”自己的老婆，并在魔术俱乐部里给其他爱好者表演，但这些都无法让他成为一个更好的表演者。（花很多时间来给魔术师表演，确实是非常有害的。他们会给你一大堆的反馈，但这绝对和你从观众那里得到的天差地别。这些只会对你形成一个很强的“商业意识”起到妨碍作用。）

这个问题将我引向了整本书中所能提供给大家的最重要的建议。如果你对魔术是认真的，就去找一个定期能给普通观众表演的地方。可以做一些志愿者的工作，比如在医院里表演。或者找一个当地的小酒吧，成为一个常客，让自己因魔术而广为人知。不久之后，每次你去酒吧，都会有人让你表演魔术的。

很多业余魔术师都能找到一家餐厅，那里的经理会适当付给他们一些费用，并让他们每周做两次沿桌表演。如果他们不愿付费，你也可以免费表演。（一些在餐厅里表演的职业魔术师，也许会对我说的表示不满，但是对于有能力的职业魔术师来说，你根本算不上什么威胁。另外，你以为他们一开始都是怎么当上餐厅魔术师的？）

许多年前，我的好友鲍勃·埃利奥特意识到他需要更多给普通观众表演的经验。于是便在坦嫩魔术店的柜台上，做一周一次的免费表演。在空闲的时候，他会为顾客表演一些他自己的魔术。（不管别人怎么告诉你的，但多数魔术店的顾客都是普通观众。）几个月内，他的表演能力就有了戏剧化的提高。这些做起来可能真的不太容易，但如果你对自己的魔术是认真的，那么一定会找到一个能够定期为普通观众表演的地方。

正是因为表演的机会有限，所以我才认为之前讲过的“复盘”练习，以及“失败预期”对业余魔术师而言，真的很有价值。职业表演者因为有更多的表演机会，所以势必能进行自我完善。经过几百场演出之后，即使是最愚蠢的表演者也能知道，这种方法比那种好，这个魔术效果比那个强，观众会在他说这个或者做那个的时候给出不错的反应。

所以，如果你是一位表演机会有限的业余魔术师，那么你就必须成为一个快速学习者。如果你准备提高，就必须在有限的表演中领悟更多。我相信，以你自己的研究，加上我书中给出的建议，一定能帮助你在有限的表演机会中学习到更多的东西。

就像奥尔德斯·赫胥黎说的那样，“所谓经验，并不是你碰上的事情，而是碰上这些事情时你的处理方式。”你无法仅靠一本书，就成为一个优秀的表演者。但如果将表演经验和一本好书结合起来，一定要比单纯从经验中获取知识成长得更快。现在你手上已经有书了，再找个地方去寻找经验吧。
