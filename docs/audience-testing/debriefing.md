# 复盘

建议大家每次在给普通观众表演完之后，都进行一个“复盘”。做起来十分简单，只要在心里回想一下表演的过程，看看能从中学到什么就好。“复盘”时，你必须在表演之后一有机会独处，就在心里回放整个表演的过程。在心里纵观一下整个表演。留心你得到的观众的每一点反馈。回想每个魔术中你得到的每一次反应，或者没有得到的反应。

主要关注一下观众有反应（或者缺少反应）的部分，会不会让你感到惊讶或者是困惑。你可能还想把它们记在一张纸上。正是这些预料之外的东西为你提供了最好的学习机会。当观众的反应完全符合预期时，你会感到喜悦和安心。但当它出乎意料之外的时候，也正是值得你学习的地方。心理学家把这样的经验称为“失败预期”。每次你在表演中体验到“失败预期”的时候，都要牢牢抓住这个机会，提升你对于观众心理的把控。

观众那些“惊讶”的反应，可能来自一个比预期更强的效果，或者没有预期那么强的效果；可能来自一处你并没有预料到观众会笑的点，或者一个效果中与你预期不同的点；可能来自一个效果表演时或者表演后，观众做出的意料之外的评价，也可能来自一句对你而言毫无意义的话。

注意到观众的反应之后，就要努力思考为什么他们会有那样的反应。理解“为什么”，才是形成“商业意识”最为重要的。仅仅留心观众对你的表演作何反应，确实有一定的价值。它能让你知道，下次在表演相同魔术的时候，该做出什么样的预期。但你的目标应该放得更长远一些。你不仅应该知道观众对你表演过的效果作何反应，还要能准确地预测出他们对你从没表演过的效果有何反应才行。这种预测能力，才是“商业意识”的本质。而这些都源于为什么你要了解观众的反应这个问题。

当你仔细研究观众那些预期之外的反应时，要尝试站在观众的角度来思考问题。他们为什么会有这样的反应，他们是怎么想的？你要像一个精神科医生那样，总是问自己，“嗯，他到底是什么意思呢？”

在你开始探寻观众的想法之前，一定要以这个为前提：无论观众说什么，或者做什么，总是有理由的，虽然你现在还不清楚它具体是什么。如果某位观众对你的某个魔术提出了一个明显不正确的解释，那么你就必须意识到，他并没有理解这个魔术。你可能需要改变一下它的表演方式，强调它是不可能以这种方法来实现的。

说了这么多，我必须承认一点，偶尔你也会从个别要么特别蠢，要么特别固执的奇葩观众那里得到一些奇怪的评价。千万别因为这些而抓狂。我的个人经验是，如果我从一位观众那里得到了一个真的难以理解的评价，那么我会把它记在心里，但不会为此感到担忧。如果以后在同一个魔术中，又从其他观众那里得到了相同的评价，那么我才会把它当作一个问题来看待和处理。如果两位观众都对你的魔术做出了同一个“特别”的评价，那么你就能确定观众中的其他人应该也是这么想的，尽管他们没有走上前来告诉你。
