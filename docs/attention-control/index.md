# 第十八章 『控制注意力』

> “要用思想来引导观众。”
>
> ——劳伦斯·奥利维尔[^1]

魔术师们一谈到错误引导，都会讲一大堆东西。这都可以理解，毕竟错引是使魔术产生效果的基石之一。然而，所有关于错引的讨论，都有一个缺点。它会让魔术师们认为，错引是可以脱离现实而凭空创造出来的。可以在关键动作发生之前，想让观众看哪里，他们就会将注意力集中在哪里。而就在这个时候，使用一些“错引”。

任何使用这种方式的人，都会发现他的错引其实并不管用。因为这才是使得错引产生效果的最大秘密：错误引导不过是控制注意力中，众多主题里的一个方面而已。你必须在表演中的每时每刻，都去控制观众的注意力才行。不然，他们便无法搞清整个效果的来龙去脉。只有做到这一点，你才能在秘密动作发生之前，轻易地将他们的注意力转移到别的地方。

控制注意力主要包含两个方面：抓住观众的注意力，以及引导观众的注意力。目前为止，我们探讨的多数话题——实质意义、情景意义、戏剧结构、节奏等等——这些都会帮助你抓住观众的注意力。现在我想以大家喜欢的讲故事的方式，来谈谈如何引导观众的注意力。

[^1]: 劳伦斯·奥利维尔（Laurence Olivier），英国演员及导演。
