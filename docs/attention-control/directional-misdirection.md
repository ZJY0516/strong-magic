# 错误引导的方向性

“错误引导”这个术语，在魔术中常常意味着两种完全不同的东西，而且很多人时常会混淆这两个不同的概念。一种我们可以称之为“物理错引”：防止观众看到你做过的事情。另一种我们称为“心理错引”：防止观众发现你做过的事情。“心理错引”无非就是欺骗的心理学。整本书讲解的都是这个问题。所以这里我只想探讨一下“物理错引”，不是控制观众的想法，而是通过控制他们的注意力，来掩盖秘密动作的这部分内容。

之前我早已说过，“错误引导”不过是“控制注意力”这个更大主题的一个方面而已，如果你已经掌握了控制注意力的相关工具和方法，那么你就已经知道了关于“错误引导”所需了解的大部分内容。

记住，想要将注意力从某件东西上引开是不可能做到的；你只能将注意力引导到某件东西上。所以，在“错误引导”中，第一步就要先决定，你想把观众的注意力引向什么东西。而这不应该是随意就决定的。从理论上讲，它都应该是效果在逻辑上的“信息源”。换句话说，它应该是你想让观众看到的东西，即使接下来你不打算做什么动作。当决定了想让观众看什么之后，再使用控制注意力的工具，让他们去看它。

例如，假设你想表演一套“单杯球”流程，需要借助错引来完成最后的大球上托。那么当你抬起杯子，最后一次展示小球的时候，就可以用杯子的后沿轻轻碰一下小球。这会让小球在抬起杯子的时候，向前滚一小段距离。小球的运动会吸引所有的目光，这样便为你上托大球提供了必要的错引。

**将“内在兴趣”作为“错误引导”**：最强的“错引源”便是对“内在兴趣”的利用。这一点和柔道类似。在柔道当中，你必须使用对手的力量来打败他。在这里，你要使用观众自身的好奇心来错引他。在这两者中，你都不会与他人的天性做斗争；而是助长他的发展，并在最后为自己所用。你让观众看他们想看的地方，并借助这一点来隐蔽某些动作。

例如，在弗农的“旅行者”中，当你用左手将第一张Ace从口袋里拿出来的时候，右手就做一个“单手藏顶牌”[^1]的手法，将第二张Ace藏在手中。这个错引就非常完美，因为每个人都想知道第一张Ace究竟是不是已经移动到了你的口袋里；这便是“内在兴趣”的观点。

在讲到悬念的部分，我们探讨过保罗·哈里斯的“反应能力”[^2]。我发现多数魔术师在表演这个效果的时候，都试图在观众拍到桌上的牌时，将顶牌掌藏在手中。因为你并不知道观众会怎么做，所以几乎不可能让你的动作和她的协调起来。正确的藏牌时机，应该是当观众打开她的手，确认下面的牌是否是她想的牌时。此时每个人都很好奇，她是否已经拍在了自己的牌上。而这种因为她的动作让其他观众产生的“内在兴趣”，才是你所需的最强错引。

在一个“找牌魔术”中，最强的“内在兴趣”往往都发生在你揭晓观众所选牌的一刻。我会利用这一点作为错引，并将它用在我的“九牌定位”效果中。当我把其中一张观众所选牌，从牌叠中飞向桌上之后。它会面朝下“着陆”，于是我便让一位观众帮我把它翻过来，展示给其他人看。在她这样做的时候，我就可以用另一张观众所选牌，来完成秘密折起一张牌的手法了。

下一个很强的“内在兴趣”，也发生在“找牌魔术”中。就是当观众看着她选到的牌，并将它展示给其他人的时候。我会用这一刻作为错引，在一个效果中做一次“翻牌”[^3]的手法。甚至还用它做过偷换整副牌的错引；它就是如此强大。

所有这些例子，都只不过是控制注意力的工具在“错误引导”方面的特殊应用罢了。然而，“错误引导”也能提升到一个超越这八种工具的高度。让我们看看它是如何做到的。

**交叉运动**：虽说“错引动作”应该和“秘密动作”同时发生，但也不是绝对的。假设我想在取出外衣内侧口袋里的钱包时，同时将一张掌藏在手中的牌放进钱包里。当我藏着牌的右手伸向钱包的时候，左手同时将整副牌放在桌上。那么我的目的就是让观众盯着将牌放在桌上的左手，而不是藏着牌伸向口袋里的右手。

我们早就知道，人的眼睛会盯着运动的东西看。但还有一条推论也很重要，那就是当两个物体运动的时候，眼睛会盯着先动的物体看。如果我的右手在左手将牌放在桌上之前就先伸向了口袋，那么便无法达到错引的目的；因为观众会先盯着藏牌的右手看。如果两手同时运动，我就无法控制观众会盯着哪只手的动作。为了达到我的目的，拿牌的手必须比藏牌的手先动片刻，这样才能吸引观众的注意。

但无论如何，先动（拿牌）的手也不能比后动（藏牌）的手提前太长时间，或者在后动的手运动结束之前，就早早完成了自己的动作（放牌），要是这样的话，观众的注意力便又会回到后动（藏牌）的手上。

[^1]: 单手藏顶牌（One-hand Top Palm）。
[^2]: 反应能力（Reflex）。
[^3]: 翻牌（Half-Pass）。
