# 让人分心的事情

> “如果你想一直受到（读者的）关注，就要避免出现使人分心的事情。”
>
> ——加里·普罗沃斯特[^1]，《让你的话管用》

控制注意力既有积极的一面，也有消极的一面。一旦你决定了效果中的每一步想让观众的注意力集中在哪里之后，就可以使用我们之前讨论过的“控制注意力的工具”来将观众的注意力引导到那里。这便是控制注意力中积极的一面。然而，你还必须消除每个效果当中，那些会让观众分心，以及暗中破坏你控制注意力技巧的元素。也就是排除那些由于控制注意力所引起的消极的一面。

观众很容易就会分心。当他们面对究竟是关注表演者所展示的东西，还是那些让他们分心的事情时，他们往往会选择后者。这也是为什么你要确保他们不会面临这种“两难”选择的原因。

让人分心的事情便是错误引导的反面。任何在正确的时刻可以作为错引使用的东西，也能在错误的时刻成为让观众分心的罪魁祸首。这就意味着，如果你理解了错引，也就理解了什么是需要消除以及避免的，那些让观众分心的东西。

运动绝对是一个很强的吸引注意力的工具。同时也是魔术表演中，最容易让观众分心的源头。表演者常常会不由自主的坐立不安，并将它作为一种释放紧张情绪的方式。比如不停地改变身体的重心，从一只脚换到另一只脚。不停地做一些毫无意义的拨牌动作。这些行为都很容易让观众分心，从而不再关注你想让他们关注的地方。

因为上述动作都是无意识的，所以你自己很难察觉。如果你有机会观看自己的表演带，那么这就是一个让你去除表演中使观众分心动作的好机会。或者找一位朋友，让他来看你的表演，从中找出那些可能会让观众分心的动作。

当你作为一位表演者的经验愈加丰富，便会对自己的每一个动作越加敏感。下面这些原则一定要遵守：不要做任何多余的动作，无论它再小。总的来说，你一次最好只做一个动作。唯一的例外，便是使用动作作为错引的时候，可以用一些公开的动作来掩盖秘密动作。

永远记住，你的第一要务就是讲故事，尽可能把你的故事（效果的故事）讲清楚。你必须排除任何会让观众分心，从而影响你实现这个目标的东西，无论你有多喜欢它。这可能意味着，你要去掉一些自己很喜欢的花式动作，或者放弃一个有意思的梗。这对幽默效果而言，实现起来可能非常困难。魔术师们时常发现，即使一个笑点可能会让观众错过效果中的关键部分，但依旧很难放弃它。一个好的笑点只有出现在正确的时机，才称得上好。如果它出现在错误的时机，就失去了自身的价值——如果它破坏了你辛辛苦苦创造的神奇时刻，可就划不来了。

[^1]: 加里·普罗沃斯特（Gary Provost），美国作家、写作指导专家。著有《100个提高写作水平的方法》等书。
