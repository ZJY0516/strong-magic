# 绘制线路

以前有人提出，想让错引发挥作用，就必须在表演时全程控制观众的注意力，而不仅仅在秘密动作发生之前。但过去并没有强调，除了错引问题之外的控制注意力也是很重要的。如果是一位舞台剧导演，就不会担心如何隐藏秘密手法的这个问题，因为他会小心地安排每一个场景，将观众的注意力集中在他希望的地方。

同样，一位电影导演也会将每一个镜头都安排得恰到好处，这样观众就会注意他希望他们注意的东西。他还会将每一个画面组合在一起，这样观众就会关注画面中他认为重要的信息。否则，他们就可能错过一些对理解故事而言很重要的信息。

正如我之前所说，魔术是一种“叙事”的艺术。每个效果都是一个以戏剧形式讲述的故事。所有的戏剧艺术形式，不管是戏剧、电影还是小说，本质上都是在以同样的方式发挥着作用。它们展示给观众的都是信息碎片。而这些信息碎片相互关联的方式，以及展示它们的顺序，堆叠出了一个故事。但这些还不足以作为事实呈现在观众面前。你还要让他们关注它，理解它，记住它。

有人说，你可以将一匹马牵到河边，但是没法让它喝水。但如果你想成为一个出色的表演者，就要学会让观众“喝水”。想做到这一切的秘诀之一，便是控制他们的注意力。

电视上的魔术，就为我们的控制注意力，提供了一个很不错的范例。一位电视导演就完全有能力引导观众的注意力，因为他们任何时候都只能看到他在屏幕上给出的画面。想想你在电视上看魔术时的情况吧，有的导演选的拍摄角度很烂，而且将镜头在错误的时刻切近或者拉远。我知道这些错误有时会无意中暴露魔术的秘密，但它又将我们带回了错误引导这个我想暂时放在一边的问题上。想想就知道，这些糟糕的引导方式，很难让观众明白到底发生了什么效果。不幸的是，当在电视上表演魔术的时候，这些问题都非常普遍。

你的目的是让观众明白究竟发生了什么，并且欣赏这一切是多么的不可思议。所以第一步就要首先了解一下，观众必须吸收什么样的事实和条件，才能理解并欣赏一个效果。你的第二步便是纵观整个效果，决定每一步要传递给观众什么样的信息。如果任何步骤在传递信息或者突显关键信息时，没有发挥出它相应的功能，那么就说明整个效果的结构存在问题，需要重新加工。一定要在每一步中，精确分辨出你要传达的信息所包含的元素。亨宁·内尔姆斯把这称之为“信息源”。

你的目标就是成为一名“导游”，将你的观众平稳的从一个“信息源”引导到下一个“信息源”，直到你到达效果的高潮。任何时候，你心里都要清楚，究竟想让观众看哪里，以及为什么。整个过程不能有任何间隙。这是非常重要的。如果在整个过程中，有一刻你没能抓住并且引导观众的注意力，那么“注意力”就会像在人头攒动的百货商店里走丢的孩子一样。你很难再将他找回来了。这是你一定要避免发生的情况；永远不能放开观众的手。
