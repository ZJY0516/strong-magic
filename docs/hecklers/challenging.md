# 挑战

奥客的另一种常见形式，便是挑战表演者。会有观众对你说，“你手里藏牌了，”或者“这几张不是真正的Aces，”或者“让我们看一下这副牌的顶牌。”多数时候，这种挑战是毫无理由的。你确实没有在掌心藏牌，这几张也真的是Ace，顶牌也没什么特别的地方。事实上，只要稍微有点儿脑子的人，都知道这种挑战完全是毫无根据的。

然而，你会很自然的接受这种挑战。你会把手翻过来，证明自己没有藏牌，把这几张牌翻过来，证明它们确实是Ace，或者向挑战你的观众展示整叠牌的顶牌。

但我给你的建议是：不要这么做。你可能认为，当你向观众证明他的挑战毫无理由时，会给自己加上一分。但我想说，你就不该把自己搅进来。这个行为本身是无关对错的，但你会丧失对观众的掌控力。奥客就希望你每次在他说“跳”的时候，你就跳。这样你就成了他手中的木偶，而他成了操控你的人。他们就喜欢这样：所以只要让他得逞一次，他便会一直“奥”下去。

每次你屈服于（接受）挑战的时候，就像在鼓励观众对你进行更多的挑战。只要把自己搅进去，很快你就会发现完全无法完成剩下的表演。想找麻烦的观众只想持续引发更多的挑战。你刚解决完一个，就会有另一个等着你。他并不会因为你每次都证明他是错的而灰心丧气。相反，这会鼓励他每次都向你发起挑战，不管内容有多么的荒唐，你都必须停下来解决这个问题。

处理挑战最聪明的方法，就是完全忽视它。再说一次，只要关上你的耳麦就够了。如果你的效果结构合理，那么就无需向观众证明任何东西，他们自然会明白该明白的事情，不用你多此一举的进行说明。所以当观众提出挑战的时候，你可以假装没有听见，继续表演就好。如果他大声的、让人厌烦的、不停地重复这种挑战，让你根本没法忽视他的存在，那么不妨笑着对他说，“不是。”然后，继续进行你的表演。

让我们设想一下另一种情况。观众不停地抛出挑战，一个接着一个。你每一个都耐心解答，证明他总是错的。这样就相当于在鼓励他更具侵略性。不久，他的某一次挑战正好击中了你的要害。偶然间，你无法应对。你无法向他展示顶牌，或者让他来洗牌，或者是其他事情。因为之前的每一次你都在迎合他的要求，那么当你这次想要拒绝的时候，所有观众都会认为他已经抓住了你的要害，扒下了你的裤子。

但是如果你无视他的挑战，假装没有听见，那么最终只能不了了之，很快便平息下去。如果条件允许，方便离开的话，那么最后他肯定会独自走开。（希望他这样不会让你伤心！）别让任何人把你拉进他们的“游戏”里。你才是那个制定规则的人。

当然，我说的一切，都是以挑战者想要惹麻烦为前提的；这一点你可以从他提出挑战的荒谬程度中看出来。偶尔也会有观众因为真的怀疑而提出挑战。这也分为两种情况，第一种你可以应对，而第二种不能应对，因为观众确实猜对了。

如果你确实接受了一个无法应对的挑战（比如观众对某处表示怀疑），这就说明效果本身的结构存在问题。（这种情况发生的时候，就要仔细观察一下，看看是不是每次表演时都会在同一个地方出现这样的挑战。）你最好修改一下效果，从而减少观众的怀疑。如果实在做不到的话，就将它从你的节目单里去掉好了。

在之前的内容中，我就讲过有魔术师表演“骗了胡迪尼的魔术”时发生的故事。有观众问表演者，能否看一下整副牌的顶牌。这就是一个很合理的问题，因为这个效果本身的结构，就会暗示观众顶牌可能是一张观众所选牌的复制品。所以为了减少此类问题的发生，表演者在一开始的时候，就应该要求观众在所选牌上签名。

假设你遇到了一个合理的挑战，而且你也能够应对。比如观众想看看四张Ace的牌面，而你又正好要展示它们。那就展示好了。同时，要在心里记住，这便是一个效果结构中的弱点。如果观众对效果抱有这样的怀疑，即使是毫无根据的猜测，也说明这个效果的结构有问题。只有修改这个效果，甚至要在观众对它产生疑问之前，就（让效果本身）做出解答才行。这样才能达到两个目的。第一，它能减少表演时被打断的可能性。第二，它能减少那些怀疑这几张牌是否是Ace，但又不好意思问的观众的疑惑。
