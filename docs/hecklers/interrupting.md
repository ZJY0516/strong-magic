# 打断

偶尔，你会碰到不停地用笑话、段子或者问题打断你表演的观众。这些人，多数情况下并不是真正的奥客。他们并不想破坏你的表演。他们只是比较人来疯罢了，可能是性格的原因，也可能就是酒精的作用。然而，如果他们一直多嘴多舌的话，很可能破坏你的表演。

凭借经验，你会发现自己可以通过如何回答观众的这些评论，来控制观众打断的程度。多数时候，对于观众的种种问题或者段子，最好的回应方式，就是用一些搞笑——或者至少是有意思的话来回应。就像我之前说的，这种即兴添加的内容，可以在很大程度上增加表演的娱乐性，以及临场感。

同时，你必须意识到，自己无法一边演着魔术，一边应付和观众的对话。如果你感觉这种打断已经让表演偏离了正常的轨道，那么就必须改变一下你的策略。可以开始限制你回应观众的次数，用微笑或者完全无视来应对他们的每一次打断。

当你对观众的一次打断做出回应的时候，就相当于默许观众再一次打断你。不久，观众会觉得这种打断在表演中是理所应当的，而且他们也不会太专注于你表演的内容。当你礼貌的限制自己对此做出回应的时候，就是要让观众知道，你不想冒犯任何人，而他们也应该更加专注于你正在表演的东西。

你的目的是让观众感到足够的轻松自在，从而自发的和你进行互动，而不是让混乱搞砸你的表演。想要在自在的互动与混乱的状况中达到一种平衡的状态，就要知道，打断也得有度才行。
