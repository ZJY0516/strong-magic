# 抢夺

最危险的一种奥客，我们称之为“抢夺者”。只要你把道具放在桌上，他们就会一把拿走。

当你正在表演“杯球”流程的时候，他掀开一个杯子，看看下面有什么东西。当你表演Ace集合流程的时候，刚把一张“Ace”面朝下放在桌上，他就会立刻翻开看。

有两个因素会导致你容易遇上“抢夺者”。首先是你的威信。因为抢夺你的道具，说白了就是对你不尊重，多数会发生在你威信不高的时候。最好的解决方法之一，就是使用我在暗示章节中讲解的那些技巧，从而尽可能快速的在每场表演中建立起你的威信。

第二个很可能遭遇“抢夺者”的原因，便是领地意识。如果你摆放道具的地方，观众都视为是你的领地，那么他们便很少会动手去抢。如果你把道具放在了他们以为是自己地盘的地方，那你可能就会遇到麻烦了。因此，如果你是在一间酒店的套房里表演，而且有专门为你摆放的桌子，那么就很少会碰到抢你道具的人，但如果你在做沿桌表演，就比较容易碰到抢你道具的观众，因为他们认为桌子是他们的地盘。

因为领地意识的原因，如果想要保护好你比较“敏感”的道具，那么就最好把它放在离你身体较近的地方。道具离你越近，也就越处于你的领地范围当中；观众也就很少会动。

另一种减少抢夺情况发生的方法，便是使用一个近景桌垫。近景桌垫能够非常清楚地定义出你领地的边界。这样观众便更不容易随便抢夺你放在桌垫上的东西，因为很明显，这样会侵犯你的领地。当然，我也不是非要大家使用近景桌垫，至于是否选用它，还包含很多因素，比如你的个性、风格以及表演场所。但你应该意识到，使用近景桌垫确实能对“抢夺者”有一定的抑制作用。

最容易发生抢夺事件的场所，便是餐厅。这并不奇怪，大家应该还记得我们之前讲过的领地意识和威信吧。在餐厅里，你就不得不在观众的桌子上表演。而且，通常在餐厅的表演者，往往在刚接近一桌观众的时候，威信还并没有建立起来。观众更倾向于把他当作是一个服务人员。（所有在他们用餐时，接近桌子的不都是服务人员嘛！）

基于上述原因，当你在餐厅表演的时候，选择那些不用在桌上放东西的流程，或者是所放物品能够完全在你控制之下的流程，就显得尤为重要了（比如，你需要观众把手盖在桌上的道具上面时）。

不管你用什么方法来防止观众抢夺道具，还是会遇到各种各样的问题。所以当你遇到此类问题的时候，一定要立刻制止他。如果你不加以制止的话，就是在鼓励更多的此类行为。很快，他就会以揭秘的方式来做这件事情。

最近，我在阿根廷的布宜诺斯艾利斯，进行了一场电视表演。我打算在其中的一个魔术中，让观众在一张牌上签名，所以就把一支记号笔放在了桌上。在我开始表演前，节目主持人心不在焉的把笔拿了起来。我轻轻地从她手中把笔拿回来，然后放回了桌上。过了一会儿，她又拿起空的牌盒把玩起来。我微笑着从她手中拿回牌盒，放回了桌上。其实她的这些举动并没有什么害处，因为我还没有正式开始表演，而且她拿的这些东西也无关紧要。但无论如何，如果我没有立刻制止她随便动我东西的行为，那么在之后的表演中，她就很有可能因为拿起了什么不该拿的东西，而毁掉我其中的一个魔术。

制止观众抢夺你道具的方法，就是立即把东西拿回来，然后礼貌的告诉他们，不要动你的道具。虽然你要表现得很友好，但是坚定的态度也是很重要的。你要让观众知道，动你道具这个行为本身，与魔术的成败并无关系；你只是不想让这个行为，成为一种对你个人的侵犯而已。如果他还是继续抢你的东西，我强烈建议大家停止表演。当然了，无论是社交场合还是职业场合，你必须继续表演的情况都少之又少。而在任何情况下，只要观众拒绝尊重你，那么你就应该拒绝为他们表演。
