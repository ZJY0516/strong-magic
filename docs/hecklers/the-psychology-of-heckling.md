# 奥客心理

近景表演者所要面对的最困难的问题，便是奥客：那些大叫起哄，嘲弄侮辱，乱动东西，以及将你的魔术“揭秘”给剩余观众的人。虽然这些奥客确实是真实存在的问题，但许多近景表演者也确实曲解了更多无辜的情况。基于这个原因，我觉得我们应该先来定义一下，到底什么是奥客：奥客便是那些以破坏你表演为目的的观众。如果你不理解是什么造成了奥客出现那些行为，那么你将发现他做的事情既难以对付，又让人头疼。

影响人类行为的关键，便是理解他们的动机。奥客的动机便是嫉妒。你有他想要的东西。也就是来自其他观众的关注。全场的焦点都在你身上，而他希望在他的身上。他所做的所有事情，都是为了将观众的关注焦点转移到自己身上。

这也是为什么，即使是最富有侮辱性质的玩笑，也不会让这些奥客就此打住。我们在书里都看过类似“奥客终结者”的梗，这些梗意在羞辱他们，好让他们放弃自己的“恶毒行径”。这种方法便是我们在实际表演时经常用的策略。当奥客对你进行羞辱的时候。你就用更加聪明的方式回敬他。接着他再羞辱你，你再用另一个聪明的方式回敬他。你说的话往往比他说的更加能引发观众的笑声，但他就是不肯闭嘴。

这时你可能会想，“为什么这哥们自己意识不到，在这场‘玩笑大战’中，他并不是我的对手呢。”但你没有意识到的是，他根本就没把这一切当作一场“玩笑之战”。他把这种行为当作了对于观众注意力的争夺之战，而且他还胜利了。每次你朝他抛过去一个讽刺的梗，都会给他额外加上一分。这个可怜的小丑，不顾一切地想要博得关注，即使是被羞辱也好过被当成空气。

每次你把注意力放在他身上的时候，都在鼓励他对你进行进一步的挑衅。这也是为什么每次你尝试回敬他的时候，都只会得到变本加厉的嘲讽。

想要掌控这种局面，唯一的方式就是夺走他寻找的东西。在近景魔术表演中，99%的时间里，处理一个奥客的最好方法就是忽视他的存在。在杰伊·伊万斯《硬币的另一面》一书中，他就有一个很不错的方法来表达这种态度。他称之为“关掉你的耳麦。”

当我遇到一个棘手的奥客时，不仅会假装听不到他讲话，还会完全拒绝承认他的存在。不和他有任何的眼神接触。表现得就像视他如空气一般。

就多数情况而言，只要他意识到自己的行为没有得逞，便会开始安静下来。如果表演环境是那种，观众可以在不打扰其他人的情况下，就私下离开的场所，那么奥客通常会在表演结束前离场。这当然是我所期待的最好的结果了。

起初，你可能发现我推荐的方法很难投入实践。如果是这样的话，便是因为你正在做一件在相同情况下你绝对不可能做的事情，而且还把自己的自尊心也掺杂其中了。因为你把奥客的行为，当作是一种挑衅，你感觉自己必须用更巧妙的方式来回敬他。因为你想赢得这场“玩笑大战”。

但无论如何，这种方法都存在隐患。我早就强调过，这样做只会鼓励奥客的行为。还有一个隐患是，剩下的观众会觉得你很不友好。他们会开始认同这个你“正在讽刺”的人。毕竟，他也是观众中的一员。他可能还是其他观众的朋友或者熟人。只有当你无视了他的玩笑话之后，你才是更加深得人心的一个。当你全心全意想要让观众开心的时候，他们便会开始厌烦这个让你难堪的家伙。

确实，对我而言，最有效的“奥客终结者”便是来自其他观众的怨念。我只会在最为极端的情况下才说出这样的话，比如即使我忽视了他的存在，但他依旧赖着不下台，非要搅乱我的表演。此时我会对剩下的观众说，“看到了吧，近亲结婚就是这个下场。”

这句话总会让观众哄堂大笑，而笑声远比幽默内在的合理性更重要。这是因为，笑声本身便是观众对于奥客敌意的宣泄出口。（而且我也只会在观众对于奥客的敌意很强时，才使用这句话解围。）

我之所以特别喜欢这句话，是因为它既能讽刺奥客，又不会增强他的存在感。这是因为，这句话不像其他的“奥客终结者”的梗那样，它并不是直接针对奥客的；而是对剩余观众说的。在说这句话的时候，我并不会对着奥客说；说的时候更不会看他。而是看着剩下的观众。他们知道我在说谁。因此，奥客得到了致命一击——一个并没有指名道姓的嘲讽。

我并不是建议大家也说同样的话，只是把它作为一个应对奥客的例子而已。只要占有他们最为渴望的关注度，就够了。

最后，最致命的诱惑便是与奥客对骂，这相当于你亲手埋葬了对台下观众应该负起的责任。即使你讽刺奥客的行为博得了观众一笑，他们也不是因为魔术本身而开心的。但你的工作是用魔术让观众开心。就这个层面而言，奥客阻止了你，你就已经输了，即使你靠他获得了一些笑声。

如果真有一个特别难缠的奥客，还有最后一招：你不一定非得演下去。如果是社交场合的话，可以向剩下的观众道歉，然后把牌或者是硬币留在你的口袋里。甚至是商业表演的场合，你也可以移动到下一桌，或者在重新开始表演之前稍微休息一会儿。

如果大家按照我的建议来做，你就会非常，非常少的用到上述方式。但它就在那里。如果你真的处在一个确实无法继续表演的环境中，而又拒绝停止表演的话，那就只能是因为陷入了我之前警告过你要防止发生的那种情况：你又把自己的自尊心搅在里面了。
