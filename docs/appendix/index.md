# 附录一 『达尔文法则』

为了方便复习、研究，或者其他原因，所以我把本书最重要的观点写成法则系列。

- 1. 魔术效果发生在观众的大脑中。
- 2. "专业魔术中不存在挑战。"(弗雷德·卡普斯)
- 3. 只有对魔术效果产生影响的魔术方法才显重要。
- 4. 让观众更容易记住你想让他们记住的东西，而不是忘记的东西
- 5. 对于魔术，观众容易感到困惑，而不容易被骗到。
- 6. 你越出色，观众看的也越细致。
- 7. 如果你要将苹果变成橘子，那么请将苹果最后出现到橘子首次出现之间的时间压缩得越短越好。
- 8. 永远都不要强迫观众干某件事。
- 9. 你的工作是让事情对于观众而言变得越简单越好，而不是让事情对于你自己越简单越好。
- 10. 解释阶段的说明要尽可能令观众信服。
- 11. 令观众印象深刻的魔术条件在于观众的个人感知，而非条件的实际情形。
- 12. 任何效果只有在条件存在的时候才表演。如果效果涉及读心术，那要事先保证观众知道你可以读心。
- 13. 观众同时具有两种极端智商。当你想让他们聪明的时候，他们很蠢(比如当你想让他们注意某些细节时)。当你想让他们蠢的时候，他们却极其聪明(比如当你想让他们忽视某些细节时)。
- 14. 当你叙说某个故事时，如果可能，将自己加进去，让你自己变成故事里的英雄。
- 15. "细节决定成败。"(西鲁斯)
- 16. 对于观众而言，魔术师说得越少越好。
- 17. 每个魔术应该有一个清楚的瞬间标志着效果已经发生。
- 18. "我们相信我们所希望的。"(狄摩西尼)
- 19. 解释阶段越长，观众越不相信你说的。
- 20. 如果你能骗到魔术师，你就可以骗到任何人。
- 21. 如果一位观众可以在不做任何事情的情况下怀疑你的魔术，那么这个魔术的结构有待改进。
- 22. 观众总是对的。
- 23. 魔术不是关于欺骗的游戏，而是关于创造的游戏。
- 24. 如果你想要观众记住某个效果，不要只是表演，要推销它。
- 25. 如果你要通过效果解释某个故事，那么故事应该是真实的。
- 26. 在任何效果中，条件是最强有力的因素之一。
- 27. 任何给定的效果能支撑的表演是有限度的。
- 28. 在观众的脑海中，你只是一个普通人。不要让他们忘记这一点。
- 29. 在达到魔术效果高潮之前解决所有疑虑。
- 30. 在每个魔术中，永远在相同的情况下说同样的事。
