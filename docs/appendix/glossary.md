# 附录二『词汇表』

当我开始撰写这本书时，我很快就意识到本书内大部分的主题都很少在魔术界被讨论过，以至于没有足够词汇去描述，所以我只能自己来创造大量词汇。我也决定将最重要的名词汇聚为以下词汇表（当然还包括其他人创造的词汇），希望这些新词能作为魔术语言的开端，能使魔术表演的问题被讨论、辩论、论证。

- **accidental convincer（意外说服者）**：看起来无意识下表演的微小动作，能加强观众的信念。
- **adlib list（即兴列表）**：在非计划却预料之中的情况下，使用的即兴表演列表。
- **anti-climax（小高潮）**：任何在某效果更加高潮之前的小高潮。
- **anti-contrasting parenthesis（反对比间歇）**：指在魔术表演中，任何一个会把观众的注意力从效果成功所依赖的某个核心特征上引开的元素。（本词由阿图罗·阿斯卡尼奥创造）
- **artificial progression（人工推进）**：通过某个外在的戏剧装置对魔术表演产生的推进感。
- **audience testing（观众检验）**：在观众面前表演某个魔术来确定其反应——这是魔术师版本的现实检验[^1]。
- **the bizarre explanation formula（魔术解释公式）**：一种表演结构，这种结构中，你为某个常见问题提供魔术解释。
- **the bizarre solution formula（魔术方法公式）**：一种表演结构，这种结构中，你为某个常见问题提供魔术方法去解决。
- **character（角色）**：观众对于表演者是谁的感知；该词与 persona 相同。
- **character line（角色线）**：让观众了解表演者个性的一句台词。
- **character material lists（角色材料表）**：为了让观众信服你所表演的角色，所有你正在或以后会使用的角色材料（说话模式，道具，主题等）列表。
- **character profile（角色描述）**：角色形象列表，列举该角色的所有特征以及与此角色相关的个人经历。
- **commercial sense（商业意识）**：通过经验，预测某个魔术在普通观众面前的效果有多好的本能。
- **condition（条件）**：在某个魔术下的限制，似乎可以排除欺骗的可能性。
- **consensus reality（一致现实）**：关于什么对普通观众有效的（在魔术圈内未经证实的）传言。
- **conservation（保留）**：在魔术开始阶段，故意保留效果的强大之处，而在之后的阶段才揭示出来，以达到效果的推进。
- **convenience-driven effect（便利所驱的效果）**：以使用越少的技巧为目的而改造的魔术效果，而非以越强的效果为原则。
- **convincer（说服者）**：看起来无意识下表演的微小动作，能加强观众的信念。
- **conviction（信服度）**：观众对魔术效果的信服程度。
- **conflict-uncertainty suspense（冲突不确定性悬念）**：质疑某冲突结果而所产生的悬念。
- **dead time（时滞）**：指在魔术师表演中，任何观众不感兴趣的时间段。
- **debriefing（解说）**：在内心评估某段表演，以寻找新的见解，并且辨别出哪些地方需要改进。
- **deteriorating conviction（信念恶化）**：在表演进行过程中，魔术的进展导致观众开始质疑在说明阶段形成的结论。
- **directional misdirection（定向错引）**：在你做秘密动作时，引导观众注意力到其他地方。
- **emotional belief（情感信念）**：这是“本能上”的信服，即使违背此人智力上的信念，也可以让此人信服。
- **emotional memory（情绪记忆）**：对于某些事的直觉记忆，比理智记忆更容易消散。
- **expectation failure（期望失败）**：观众的实际反应与你所期望的不一致。
- **expository phase（说明阶段）**：表演者在开始表演魔术前的情况/背景解说阶段，这也是整个魔术效果的一部分。
- **Fitzkee's fallacy（费兹奇的谬论）**：此谬论相信魔术没有固有的娱乐价值，因此只能通过融合喜剧或音乐等其他艺术形式来娱乐观众。
- **foreshadow（前兆）**：在魔术效果中，前兆是为了让观众准备好效果后阶段会发生的事，前兆通常采用观众直到效果结束才会完全理解的方式。
- **incidental convincer（偶然说服者）**：一个明显是更重要动作的附带小动作，有助于加强观众的信念，即一切都是应该这样的。
- **incidental magic（偶然魔术）**：在表演主魔术效果的过程中，随意表演的小魔术效果。
- **induced response（诱导回应）**：操纵观众做某事的同时，让观众认为这是他自己的想法。
- **intensity misdirection（强度错引）**：当你做秘密动作时，让观众放松警惕的错引。
- **interest curve（兴趣曲线）**：指在表演中，观众不断变化的兴趣程度。
- **invasive magic（侵入性魔术）**：魔术发生在观众自己身上。
- **inversion（倒转）**：涉及道具角色互换的效果结尾。
- **inverted question（倒置问题）**：表演者对自己发起的一个问题，然后用魔术的效果去解答。
- **kicker ending（意外结尾）**：在观众以为是最终效果结尾后再次出现的魔术效果。
- **lead-in effect（前奏效果）**：用于引出更长、更复杂效果的快速、简洁的魔术效果。
- **the magical phase（魔法阶段）**：魔术效果中奇迹出现的时刻。
- **method-driven effect（方法驱动型效果）**：主要以适应某种方法而架构的魔术效果，而非以最强效果为目的。
- **meaning（意义）**：通过表演方式赋予魔术效果的额外重要性。
- **the must-believe test（必信测试）**：确定为了让效果被认为是奇迹，必须让观众完全相信某个假（或真）前提，此过程即为必信测试。
- **mystery-curiosity suspense（好奇悬念）**：因为想知道为什么某件事会发生而产生的悬念。
- **the no-contact condition（不接触条件）**：如果某效果中某物体从 A 点穿越到 B 点，请确保 A 点和 B 点不要有任何接触，并且（确保在观众眼里）没有任何其他东西从 A 点转移至 B 点。
- **the occult formula（超自然法则）**：这是一个表演结构，表演者先介绍一款道具与关于此道具的超自然故事，然后使用此道具表演一些魔术效果来证实所说的故事。
- **pacing（表演节奏）**：观众对于表演速度的感知——他们对魔术表演时间流逝的主观感知。
- **peripheral awareness（外围意识）**：当你的现场观众很多时，外围意识指保持与外围观众交流的连续性意识。
- **persona（角色）**：观众对于表演者是谁的感知；该词与 character 相同。
- **picturization（图像化）**：将道具展示在台面上，以此传达效果。
- **plot-driven effect（情节驱动型效果）**：主要以情节需求而架构的魔术效果。
- **pre-climactic stall（高潮延迟）**：在效果达到高潮前的停顿或延迟，以促成悬念。
- **prepared adlib（有准备的即兴）**：对于意外事件的明显即兴回应，而实际上是在预料到这种可能性的情况下早已准备好了的。
- **progression（推进）**：一种推进感，让人感觉每个后续的效果或阶段比之前的效果更令人感兴趣、令人印象深刻或更重要。
- **recurring situation（复发情况）**：在表演的某个特定阶段中，会不断重复发生的意外事件，因此我们可以事先预料到，并做好应对准备。
- **reverse one-eighty（效果逆转）**：效果结尾的最后一刻，效果完全逆转。
- **the second-shoe technique（第二只鞋技巧）**：在过渡或换位的多阶段效果中，在揭示第二部分之前，要表演效果第一部分的所有阶段。
- **sequencing（定序）**：效果中向观众揭示魔术事件的顺序。
- **simulation move（模仿动作）**：模仿某些完全不同动作的技巧（而不是看起来什么都没做）。
- **situational meaning（情景意义）**：通过魔术发生的情景而赋予效果额外的重要意义。
- **staggered movement（错落动作）**：协调错引动作和秘密动作的动作，以此让错引动作更加吸引观众的眼球。
- **style（风格）**：“表达或完成某事的方式与其实质不同”【韦伯斯特字典】
- **substantive meaning（实质意义）**：通过魔术涉及的主题对象而赋予效果额外的重要意义。
- **subtext（潜台词）**：通过效果或表演传达的任何隐含或无意识信息。
- **tempo（节奏）**：你表演的速度。
- **tension-anticipation suspense（预期紧张悬念）**：希望体验预期结果所产生的那种悬念。
- **the theatrical fallacy（戏剧性谬误）**：相信魔术效果是为了肯定戏剧性表演，而非表演是为了增强效果。
- **thematic discrepancy（主题差异）**：效果里的任何使表演主题相违背的元素。
- **timing（时机）**：两件事物之间的时间关系，可以是表演中的词语或者动作。
- **tone（语调）**：表演者对他表演材料的态度（严肃，异想天开，诙谐，讽刺等）。
- **twist ending（意外结尾）**：与观众所预料不同的结尾。
- **undersell（低估）**：将魔术高潮视为无足轻重，以间接强调它。

[^1]: 在心理学中，现实检验（reality testing）是心理治疗的作用，通过其目标或现实世界和人的关系反映在观察员评估，在治疗时段感到可以安全去实验新行为，接受他人的支持及回馈，使改变成为可能。现实检验是用来区分来自外部世界的思想和感情的内心世界的过程是在心理和行为治疗常用的技术，最初是由弗洛伊德设计。如判断电影画面的抢劫是假、床戏是真；判断朋友言谈的玩笑是假、感情是真。
