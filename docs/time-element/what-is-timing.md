# 何为时机？

时机是魔术中最重要的问题之一。如果从魔术著作中看，它似乎也是最神秘的事物之一。有多少次当你读到一个确切的动作“要依靠时机”的时候，刚想一探究竟，却发现作者略过不提？许多魔术作家都觉得它实在太难以捉摸，所以只会简单的提一下。虽然时机非常难以掌握，但却十分容易理解。就和多数技巧一样，你理解得越透彻，学的也就越快。让我们先从定义开始：所谓时机，便是两种不同事物间的时间关系。

听上去很简单，难道不是吗？然而，这个简单的定义却是理解整个问题的关键。一旦你能抓住“时机总是两件事物间的时间关系”这个本质，那么魔术中的每个时机问题就都很容易分析了。这只不过是一个辨别两种元素的问题，并对它们之间可能的时间关系进行检验：同时做A和B，在B之前做A，在A之前做B，然后改变A与B之间的时间长短。

时机对魔术非常重要，而且几乎关系到表演中的方方面面：手法、错引和台词。让我们举几个具体的例子，看看时机是如何在这些类别中发挥作用的。
