# 何为节奏？

节奏是目前为止，在表演时间中最重要的一个方面。因为它是观众在表演进行过程中，实际体验时间的一种方式。我们一次又一次的发现，其实所有真正重要的事情，都发生在观众心里。

这便是我对节奏的定义：所谓节奏，便是观众对表演速度的感知——即他们在表演进行过程中，对于时间流逝的主观感知。一场快节奏的表演，会让时间看似过得很快；而一场慢节奏的表演，会让时间看似变得漫长。

“看似”一词，在上述观点中非常重要。因为我们这里讨论的是观众对于时间的感知，而不是钟表上对于时间的记录。就像考尔斯·斯特里克兰在《表演的技巧》中提到的：“一分钟的时间，会根据体验的不同而发生变化。一场还剩最后一分钟就结束的球赛，可能对于一方的啦啦队员来说，长得难以忍受。但对另外一边的啦啦队来说，却短到不可思议。”

如果你对表演中节奏是否真的那么重要还抱有怀疑，那么不妨思考一下下面这个问题。快节奏通常是区别职业魔术师和业余魔术师的唯一标准。即使是技巧最娴熟，也最受尊敬的业余魔术师，他们的节奏对于职业魔术师而言也很慢，这几乎无一例外。即使是最糟糕的职业魔术师，至少也知道快节奏的表演更能抓住观众的注意力，这也几乎无一例外。

业余魔术师通常会因为下面几个原因而放慢表演的节奏。首先，因为他们常常给朋友表演，而这些人要比陌生观众更加“放肆”一些，或者他们会给其他魔术师表演，而这帮人看上去似乎愿意坐下来全程盯着他，想要从中找出破绽。其次，业余魔术师也常常会给一些因为某些事而走不开的观众表演。但在许多职业近景表演中，魔术师是要与其他表演者竞争的，所以他们不得不加快节奏，从而迅速的留住观众。

最后，因为观众并没有期待从业余魔术师身上看到职业的娱乐水准，所以他们对慢节奏的表演也更加宽容。但别搞错了；不管你是职业的还是业余的，只要你以职业的节奏来表演，一定会得到观众更强烈的反应。
