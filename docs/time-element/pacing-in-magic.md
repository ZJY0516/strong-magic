# 魔术中的节奏

因为节奏涉及的是观众对于时间的主观体验，所以节奏讲的并不是“说话快”或者“动作快”；节奏探讨的是是否有兴趣的问题。之前我们讲过，魔术效果可以分成两个阶段，“解说阶段”和“魔术阶段”。而魔术中的节奏，涉及的几乎全是如何保持观众在“解说阶段”的兴趣问题。

魔术师常常会嫌一个效果太长。然而，魔术本身的长短与它的娱乐价值并没有关系。所以一个魔术实际的长短并不是问题，节奏才是。只要魔术师说一个魔术太长，那么他们的意思一定是这个魔术的“解说阶段”很拖沓。

因此，一个“雄心纸牌”流程的长度也许是“Ace 集合”的两倍，但它的节奏却快得多。一个好的“雄心纸牌”效果，几乎不会有停顿。相比之下，一个“Ace 集合”魔术，就需要在揭晓十秒钟的效果之前，花很长时间来放牌。但这并不意味着“Ace 集合”就不是一个效果很强的魔术。而是说，只有让它的“解说阶段”不那么拖沓，它才会变强。

另一种看待节奏的方式，便是“死亡时间”这个概念。任何时候当某事发生时，观众毫无兴趣，那么这便是你的“死亡时间”。节奏要做的就是审查你的表演，剔除里面每一秒钟的“死亡时间”，就像给花园除草那样。以下便是“死亡时间”最常见的原因，以及你力所能及的事情。
