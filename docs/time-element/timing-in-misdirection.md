# 错引中的时机

在错引中，很容易就能分辨出需要协调的两种元素。一种是用来吸引观众注意力的“错引动作”，另一种是需要隐藏的“秘密动作”。通常左右手的动作之间，都有时间上的联系，当一只手公开地从口袋里拿出一张牌的时候，另一只手就秘密做一个掌藏顶牌的动作。还有一个例子是，当一只手拿起一枚硬币的时候，另一只手就把一枚藏在掌心的硬币落膝。

但无论如何，错引都会涉及到将观众的动作与表演者的动作相互协调的问题。当一位观众被要求做某事的时候，他的动作不但会引起自己的注意，还会吸引其他观众的注意力。因此，你还可以使用观众的动作作为错引，来掩盖你的秘密动作。

交叉运动也是关于错引中时机问题的一个很有意思的方面，这个我们会在之后的“控制注意力”章节来进行分析。
