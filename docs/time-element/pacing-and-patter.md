# 节奏与台词

> “在你的表演中，尽量少说话。”
>
> ——J.N. 庞辛，《新白魔法》[^1]

> “少说废话。”
>
> ——斯特朗&怀特，《风格的元素》[^2]

现在我要给出大家一个表演中最重要的建议之一：别说太多话！鉴于你必须努力用台词来描述效果、植入暗示、创造气氛、塑造角色，所以你可能认为，非得说很多话才行。虽然没什么比这更加远离真相，但是我们却依旧容易深陷其中。正如许多电影因为太过依赖对白而牺牲动作最终毁于一旦那样，许多魔术也会因为太过依赖台词而牺牲效果被毁掉。

你常常会看到这样的失误，发生在那些表演中称之为“新改变”的地方。比如，一个之前只专注于手法的魔术师，决定要提高一下自己在表演方面的能力，好让它和自己在技巧上的能力相配。不久之后，这个原来简单粗暴的表演者却变成了一个话痨。以前他三分钟就能演完的魔术，现在却要六分钟，结果只会让观众更加无聊。一些很杰出的手法达人，都成了这个陷阱中的牺牲品。

还有一些魔术师似乎已经深陷魔术之中无法自拔，倒霉的观众也只好听他们没完没了的瞎扯。我曾经就遇到过这样一个极端的例子，大概是我二十多岁的时候，发现纽约的魔术圈里有一位常客，是个老先生，现在已经不在了。

他最声名狼藉的一个表演，便是“胡迪尼的纸牌魔术”[^3]。这是一个让牌盒里的 K 与牌盒外的 Q 相互换位的双牌转移魔术。（至少，我认为效果就是这样的。）他的展现方式与胡迪尼和他的妻子贝丝表演的那个“换人箱”[^4]有关。这种主题的台词，是否真的能增强效果，还是有待商榷的。但无论如何，在这个老先生的例子当中，台词无疑让整个表演显得很空泛。

他会把黑桃 K 从牌叠中拿出来，并交给观众检查。在观众看这张牌的时候，他便开始用严肃的声音说：“哈里·胡迪尼，原名埃里·希韦斯，在威斯康星州阿普尔顿的一个小镇长大，并在那里度过了一个平凡的童年。他最喜欢的运动是棒球和冰球……”

说了大概五分钟之后，他会把黑桃 Q 从牌叠中拿出来，交给观众检查，并饶有兴趣地对贝丝的童年生活进行同样的描述。这个魔术里有十二分钟的时间，观众看不到任何的魔术效果。但是，任何还没有昏昏欲睡的观众，都已经得到了关于胡迪尼和他妻子贝丝的足够多的信息，它们完全可以拿来写一部传记，来与卡尔·桑德堡[^5]的《亚伯拉罕·林肯传》[^6]一较高下。

那些天我关于魔术的野心之一，便是彻底搞清这个纸牌魔术到底是什么效果，但我必须承认，我从来没成功过。我总会在他讲到“哈里在纽约的希波德罗姆剧院表演他那著名的‘消失的大象’效果”时放弃。幸运的是，表演者一直专注地在背诵胡迪尼的财务记录，所以没有发现我溜走的事情。因此，我从没坚持看到过最后，我觉得应该称它为“一个让人无法忍受的魔术”[^7]。

多少台词才算多，其实从某种程度上讲，这个是表演者的个人问题。但一定要记住，如果观众只是听某人讲话的话，那么很快就会感到疲惫。过多的台词会完全破坏你的节奏。

### 叙事VS背景

从前，小说家们常常会在故事的中间稍稍休息一下，用几页哲学式的叙述来详细描写一下人物，甚至只描写房子、房间或者其他物理环境。但这种方法不再流行了。现在的作家会在推进情节走向的同时，在大脑中思考其他许多东西。你也应该把同样的策略用在魔术上。

我一开始就说，魔术是一种叙事的艺术：每个魔术效果都是一个故事。故事的描述一般分为两类：叙事描述和背景描述。（背景描述的另一种叫法是“解说（解释；说明）。”然而这个词之前已经在“解说阶段”中用到了，所以为了避免大家混淆，此处不会再用。）任何推动故事发展的描述都叫“叙事”；任何理解故事必须的描述都称为背景。

如果在一个场景中，主角徒手干掉了歹徒，这便是叙事。然而，作者为了展现这个场景，就必须在之前做好铺垫，比如这个英雄以前是个受过训练的特种兵，所以能够徒手杀人。这些描述便是背景。环境描写、情节设定、人物生平，以及故事开始前发生的事情，所有这些就构成了背景。总的来说，快节奏意味着将精力集中在叙事部分，而尽可能把背景缩减到最小。这些方法与其他叙事结构一样，同样适用于魔术当中。

（任何你为了让观众欣赏效果而做出的）解释构成了背景。这些背景描述常常能提高效果的冲击力。它们还可以制造气氛，或者帮助你完善人物角色。一定数量的背景描述，可能对一些特定效果的成功十分必要。但无论如何，如果表演因为背景而变得头重脚轻，观众肯定会感到无聊的。

你可能有一套非常棒的桥牌表演，而且经验告诉你，如果给观众讲解一下桥牌游戏的简单规则，效果可能会更好。但是，当你发现自己必须得先花五分钟的时间，来教观众如何打桥牌，这样他们才能看懂这个效果的时候，那么就请忘了它吧，或者只演给那些懂桥牌的观众看。

很多年前，在一场近景魔术大会的比赛中，我就碰到过这样的一个例子。如果观众没有具备大量的背景描述，那么他便看不懂魔术师的表演。效果是这样的，魔术师会展示一个装满了电线的盒子，但这个盒子里的电路，明显是违反物理定律的。当然，多数观众对于应用在电路中的物理学定律都有点摸不着头脑。因此，魔术师在表演这个效果之前，就电路的工作原理问题，给观众好好的上了一课。（我个人一直期待着休息的铃声，好让我在重新开课之前跑出去玩玩。）

这绝对是一个无可救药的魔术效果。没有背景描述的话，完全无法理解。有了背景描述也会变得更加无聊。如果情况更糟的话，观众甚至会假设，表演者在讲解电路原理的阶段就骗了他们，所以后面的魔术才能成功。如果一个效果非得让观众具备大量的背景知识才能理解，那么你最好还是忘了它吧。

其实，普遍问题并不是一个效果需要那么多的背景描述，而是表演者觉得不管是否需要都必须提供很多背景描述。有一个常见的例子，心灵师如果不给观众科普整个二十世纪关于超能力研究的历史，就没法用 ESP 卡片表演。同样，有些魔术师如果不先给观众开一个十分钟的有关占星术的讲座的话，就没法开始一场以占星术为主题的表演。

曾经有一个这样的例子，让我记忆犹新。当一位啰里啰唆的魔术师，在一个魔术大会上表演的时候，他错误的请了豪伊·施瓦茨曼[^8]来协助他完成表演。（我个人认为，这种行为本身就是在自己找死。）下面我会对发生的事情，进行一个略有删减的描述。

表演者一开场就滔滔不绝的讲起了他的近景牌垫！（我发誓这不是我瞎编的。我感觉他是想着逗观众开心。）说了三四分钟的废话之后，他表演了第一个魔术效果：变出了一个顶针。当观众从他的这个奇迹中回过神之后，他又开始论述逻辑与魔术的不同。（我感觉这也是为了娱乐观众。我必须承认，这些和他对近景牌垫的描述一样有趣。）

在第二个魔术效果发生之前，仅仅只隔了两分钟或者更长的时间：他把顶针给消失了。然后便继续回到他关于“逻辑VS魔术”的布道之中。为了讲述两者的区别，他还提供了无数毫无诚意的例子，并时不时的停下来对豪伊说：“豪伊，你懂我的意思吧？”

上述过程，让施瓦茨曼只剩下一脸的无聊与煎熬。整个表演中，大概有十分钟的时间没有任何魔术效果，而且还问了豪伊很多遍，“豪伊，你懂我的意思吧？”而豪伊只能一脸愁容的看着他说，“那个该死的顶针哪去了？”

当然，需要多少背景描述，都取决于你能让它们多有趣。赛·恩菲尔德[^9]曾经给我表演过“时空隧道”[^10]效果。他用了一段很长的关于四维空间的概念做为序言。接着开始从理论上解释，如果我们生活在一个只有长和宽的二维世界中究竟会怎么样。并通过在桌面上滑动牌来说明这个问题。然后他解释说，如果这个平面世界里的居民，看到了三维世界中原来还有深度可以运动，那么这对他们来说是多么的神奇。他们将完全无法理解自己看到的东西，尽管这对我们来说再平常不过。他边说还会边提出几个假设的例子。

接着他开始谈起我们的三维世界，并解释四维世界中运动的东西，在我们看来是个什么样子。我可以诚实的告诉大家，他讲的东西都太让人着迷了。当他开始表演“时空隧道”效果的时候，我已经被深深地吸引了，我只想说，“这些都无所谓了；请跟我讲讲多维世界的东西吧。”

这个表演启发了我，我也想在自己版本的“时空隧道”效果中，加入一些四维世界的内容。但是我缺少赛·恩菲尔德那样“科普达人”般的口才，所以我表演中关于四维世界的内容会相对简短一些。当魔术表演到一半的时候，我会看着观众说到，“它与四维世界有关；但具体是什么关系，我也不太清楚。”

说到这里，我想告诉大家的是，在表演中加入背景描述，这本身没有问题。错的是没有把握好背景与叙事之间的平衡关系，这才是不对的。必须让观众知道，表演是在持续向前推进的。如果他们感觉你在“讲课”的时候一切都慢慢停了下来，便会感到无聊。

请大家务必记住这条原则：观众总是需要边听边看的。所以除了偶尔用简短的介绍来为魔术做铺垫之外，你要尽量避免只说台词而停下手上与效果相关的动作。动作中停下的间歇，总是意味着过多的背景描述。你说的和做的要协调一致。如果你发现自己需要不停地停下来，好让台词能够赶上表演的过程，那么就说明你讲的话太多了。

台词，无疑是你表演中最重要表达的工具，但必须巧妙地使用它才行。如果列出台词应该具备的所有其他特点，那么一定别忘记加上“经济”这一条。你要像一位优秀的短篇小说作家那样，让自己说出的每个字都很重要才行。每句每段更要精挑细选，做到完美。
