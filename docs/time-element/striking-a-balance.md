# 打破平衡

在下面的讨论中，我想告诉大家，虽然节奏很重要，却不是唯一需要关注的问题。事实上，正是这一点使得达到好的节奏成为一种挑战。节奏常常会与细节、可信度、人物描述，以及气氛产生冲突。（例如，科幻作家克拉克·阿什顿·史密斯[^1]就曾经抱怨说，“问题在于，如何在快速的行动中，营造合适的气氛。”）

确实，节奏是艺术与商业间的核心冲突之一。如果把英格玛·伯格曼[^2]电影的节奏与史蒂文·斯皮尔伯格[^3]电影的节奏，或者将陀思妥耶夫斯基[^4]小说的节奏与罗伯特·鲁德勒姆[^5]小说的节奏相比较，不管你如何看待他们，都必须承认，还是斯皮尔伯格和鲁德勒姆的作品更卖座。

作为一名魔术表演者，你自始至终都要在平衡下面这些冲突间纠结：幽默VS神秘，悬念VS情绪记忆，节奏VS其他（当然，还有一点是半吊子魔术师要担心的，那便是观众影响力VS操作难易度）。当冲突中包含节奏时，只要记住下面这点就好：如果无法抓住观众的注意力，那么你什么也做不了。如果你的节奏太慢，就无法长时间抓住他们的注意力。

[^1]: 克拉克·阿什顿·史密斯（Clark Ashton Smith）自学成才的美国诗人、雕塑家、画家，及恐怖、科幻小说作家。著有《The Star-Treader and Other Poems》《The Hill of Dionysus》《The Collected Fantasies of Clark Ashton Smith》等作品。
[^2]: 英格玛·伯格曼（Ingmar Bergman）瑞典导演、作家及制片人，曾在电影、电视、戏剧和电台工作过。
[^3]: 史蒂文·斯皮尔伯格（Steven Spielberg）美国电影制片人。他被认为是“新好莱坞时代”的创始先驱之一，也是电影史上最受欢迎的导演和制片人之一。
[^4]: 陀思妥耶夫斯基（Dostoyevsky）俄罗斯小说家，短篇小说作家，散文家，记者和哲学家。
[^5]: 罗伯特·鲁德勒姆（Robert Ludlum）美国惊悚小说作家。代表作有《猎杀红色十月》、《爱国者游戏》、《燃眉追击》《恐惧的总和》、《彩虹六号》等。
