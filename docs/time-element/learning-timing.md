# 学习掌握时机

想要学习如何掌控时机，确实只能从表演经验中学习。因为你必须得到观众的反馈，并持续完善你的时机。（这也是为什么一旦你停下表演之后，对于时机的把控也会迟钝的原因。）

你会发现，观众的数量越多，对完善时机而言就越好。因为观众人数一多，所有的反应都会被放大，这样你也就更容易发现细微之处的不同，或者是缺少反应的地方，从而调整自己表演中的时机。

但是只凭借表演中的经验，你也无法自动学会掌控时机。只有将经验以及对于时机中潜藏动机的理解相结合，才能让你最快的学会如何掌控时机。它会教你用不同的方法进行试验，以及在遇到和时机有关的问题，或者意外发现好的时机时，能更快地察觉出来。帮助大家理解时机问题，便是这个章节的全部内容。
