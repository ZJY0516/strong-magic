# 魔术师观众

我能给大家最好的建议，就是不要给魔术师观众表演。至少可以说，不要经常给他们表演。如果你非要这么做的话，这只会阻碍你成为一个给普通观众表演的魔术师。无论什么时候，当你给魔术师观众表演时，都要把下面几件事情牢记在心。

首先，新奇感对于魔术师观众而言是最为重要的。魔术师观众常常会对一个糟糕但新奇的表演，评价高过一个优秀但常见的表演。（这就是为什么给魔术师观众表演，会伤害你的商业感知力。）

其次，多数魔术师其实比普通观众更好骗。我知道这个观点并不流行，但长期的经验积累和观察，让我确定它是对的。我就常常看到魔术师，被一个绝对不会骗到普通观众的魔术蒙到哭。你可能会认为，魔术师观众本身熟知魔术的方法以及原理，应该更容易发现一个效果是如何做到的。在某些情况下，确实如此。但对多数魔术师来说，他们的魔术知识，好像只会让他们的头脑更加僵化。

只要魔术按照套路来演，他们就知道是怎么做到的。但如果稍稍偏离了他们原来熟知的轨迹，那么他们的大脑就立刻“歇菜”了。不断增长的魔术知识，只会限制他们对于魔术可能性的理解。他们看到双翻就能认出来（至少做得糟糕的话，肯定会的），但是他们没法把二和二加在一起。

普通观众的思维反倒更加灵活。因为他们没有先入为主的观念，也不会过多思考详细的方法，反倒更加容易获得全局思维，时常通过直觉就朝着正确的方向去了。

还有一点你要知道，人们通常认为，魔术师观众不会对表演本身有很好的反应，这一点是普遍错误的。确实有少部分的魔术师观众，非常痴迷技巧或者方法，这样他们便看不到其他的东西。但对多数魔术师观众而言，好的表演也能让他们有普通观众那样的反应。

如果你见过唐·艾伦，德尔·雷，阿尔·高斯曼，瑞恩·拉凡得，或者其他伟大的魔术师在为魔术师观众表演时的情景，就能证明我说的话了。事实上，这些表演者在给魔术师观众表演时，不会以任何方式改动他们的表演。他们会用同样的魔术，同样的方法，同样的台词，给普通观众怎么样演，就给魔术师观众怎么演。当然他们也会获得同样热情的反应。

所以当你为魔术师观众表演时，只要用同样的方式，表演平时给普通观众表演的内容就行了。你可能想要抛弃一些对他们来说极其普通的东西。但如果你的魔术本身很好，演得也好，那么它的效果就不会让人失望。最好的一点是，你不用花费很多精力来研究一些“只为魔术师”表演的内容，因为他们对数量庞大的普通观众而言，真的毫无价值。
