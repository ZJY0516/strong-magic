# 观众的注意力持续时间

如果你表演的次数维持在一定频率，很快就会发现，其实观众的注意力持续时间差别很大。当然了，这肯定会对你的表演是否成功产生影响。你必须留意每位观众，否则就只能忍受这种让人失望的经历。

我们可以简单的假设，注意力持续时间是受到某些神秘因素的影响——比如月亮的盈亏——这种完全无法预测的因素。但事实并非如此。一旦你了解了影响注意力持续时间的因素之后，就总能在表演前，预测到自己大概会碰到何种情况。因此，便可按照具体情况来计划你的表演。

**环境干扰**：影响注意力持续时间的主要因素，便是表演时的环境。根据经验而言，其实说起来也很简单。观众越容易看到以及听到你在做什么，你就越容易抓住他们的注意力。

不幸的是，近景表演者并不是总能在这种理想的环境下表演。特别是在一些确定的职业环境中，有时环境因素可能会让观众更加难以看到或者听到你。如果室内光线比较昏暗，比如在许多餐厅当中，观众就必须更加集中精力，才能看清你在做什么。如果还有很大声的背景音乐，这在宴会中很普遍，那么观众就必须努力“竖起耳朵”，才能听到你的声音。同样，如果背景是各种噪音，比如在一个拥挤的房间里，那么他们就必须打起十二分的精神去听你讲话。

但观众是不愿意劳神费力的。所以，任何让他们觉得费力的事情，都会影响注意力的持续时间。当然，如果房间里非常吵闹的话，你就必须提高讲话的声音，才能让自己被听到。但更重要的是，你必须将自己的台词尽可能减少。删掉任何与接下来的效果无关紧要的内容。

这可能会让你感到很难受，毕竟需要放弃一些搞笑的梗，以及其他一些你明知道能够增强效果的台词。我们并不否认，精简台词确实会对表演有一定的损害。但如果观众需要很费力的才能听到你说的每一个词，那么当他们开始对此感到疲倦的时候，便会毫无反应，这对整个表演而言伤害反而更大。

同样，如果房间非常昏暗，你就应该选择一些短小精悍的效果，这样便能缩短他们需要集中注意力的时间了。你可能还需要将整个表演的时长进行精简。

当然，最理想的解决办法，就是避免在上述环境中表演。但是当你需要以此为生的时候，就并没有太多的选择余地。在这种情况下，你就必须谨慎地选择表演内容以及你的台词，并以此来减少对观众的要求。

**饮酒**：这个问题就简单多了。观众喝的越多，他们的注意力持续时间就越短。他们将很难集中精神，进行记忆理解，或者关注某件事物。

如果只是适度饮酒，那么只会对注意力持续时间有一点点影响。比如说，你很可能会发现，他们忘记了自己选到的牌，或者无法完成你的指令，除非你给出的任务比较简单。

然而，如果你打算给一帮喝大了的观众表演，就必须把他们都当成一群孩子对待。给他们表演一些很短、很简单的效果。想想那些酒吧魔术师们的最爱你就知道了，比如“杯子底下的牌”[^1]这类效果。只要你能让某个处于半昏迷状态下的观众，记得他自己选到的牌，那么就能看明白这个效果。

**身体不适**：这是很难在表演前就提前了解的一种情况。幸运的是，这个因素对于注意力持续时间而言，只有一点点影响。不过你要记住，如果房间太热或是太冷，或者座位让人感到不适，也会削弱观众集中注意力的能力。

[^1]: 杯子底下的牌（Card Under The Glass）。
