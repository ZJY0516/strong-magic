# 观众的规模

观众的规模，也是能够对你表演发挥造成重大影响的因素之一。然而，只有少数几个近景魔术师知道，给三位观众表演与给三十位观众表演的主要区别。一些魔术师可能会抱怨说，近景魔术本来就不是一次给一大群观众表演的东西。这一点，毫无疑问，是正确的。然而，由于一些商业原因，多数的近景魔术师，时常发现自己必须面对一大群观众表演。

商演魔术师，通常会吸引来三十，四十或者更多的观众。我在大学里表演时，时常一次就会碰到三十至八十个左右的观众。我还发现，在酒店套房中，也会有很多人围观。甚至是餐厅里的表演者，有时也要面对十个或者十二个观众。在魔术大会中表演的近景表演者，也必须习惯很多观众的情况。对于一场魔术大会来说，有七十个甚至更多的观众也并不稀奇。看讲座的观众可能更多。同样，魔术城堡里的近景表演厅中也能容纳三十个观众。

如果你试图使用给三四个观众表演的方式来给一群观众表演，那么就肯定会遇到问题。如果你想研究给一群观众表演时，可能会遇到的潜在问题，那么魔术大会就是个不错的地方。有时会有近景魔术师名声大振，然后受邀去大会上表演。大家满怀期待，然而他的近景秀却令人失望。这时常就是因为，他的获奖表演面对的只有三四个观众。而对一群观众的情况没有经验，他还是使用给三四个观众表演的方式，来给一群观众表演。结果当然是灾难性的。

对于近景魔术师来说，给一大帮观众表演的主要挑战，就是可听性和可视性的问题。一定要知道，当为很多观众表演的时候，让他们听见你，要远比让他们看到你更重要。如果让我在“观众能够清楚的看见我，但很难听到我讲话”，以及“观众能够清楚的听到我讲话，但是看不清正在发生什么事情”，这两种情况间做出选择的话，那么我会毫不犹豫地选择让观众更容易听到我讲话的这种情况。

这样说可能大家会感到很吃惊，毕竟我们都认为魔术是一种视觉上的体验；然而，事实确实如此。不可思议的是只要观众能够听到你讲话，那么人数再多也无妨，即使后排的人几乎看不到任何东西。只要他们能听到你，就会感觉自己是表演中的一部分。而且，他们只要通过听到的内容，便能很容易知道正在发生的事情。相比之下，多数近景效果如果无法听到台词的话，只用眼睛看是很难跟上情节推进的。

给很多观众表演时，可听性问题最理想的解决方法，就是找一套附带领夹式麦克风的音响设备，然后学习如何用它来表演。（你见过多少次魔术师在魔术大会上表演的时候，是因为缺少使用麦克风的经验，而导致自己被线缠住的情况？）

因为你不能总是使用音响系统，所以也要了解一下如何解决这个问题。这就意味着你要通过横膈膜将声音“推”出来，从而提高说话时的音量，而不是通过紧绷喉咙。虽说上一些基础的发声训练课是个更好的办法，但想要找到其中的技巧，还需要不断地通过练习积累经验。

虽然可视性没有可听性那么重要，但是你依旧不应该忽视它。这里有两个你必须遵守的原则，好让近景魔术表演时，观众人数很多的时候，能有更好的可视性。第一点是：把道具抬起来。多数近景魔术师没有意识到这一点，一旦你的观众超过六个人，那么多数人就很难看清一个放在桌面上的扁平道具。这就意味着，一旦你把纸牌或者硬币放在桌上的时候，它们几乎就消失在了观众的视野中。所以你必须确保每个人在你放下它们的时候，就都已经看清楚了。

让我们举一个简单的例子。假设你要将牌叠顶部的四张牌，面朝上发在桌上。你想让每个观众都看到它们是四张K。通常的做法是，使用面朝上发牌[^1]（Deal the cards overhand, stud style）的方式，把牌发到桌上。这就意味着，发牌的时候多数观众只能看到每张牌的背面。他们只能在牌放在桌上的时候，才能看到牌面。而对多数观众而言，牌一放在桌上之后，他们就没法看到它了。但如果我们使用下手发牌（Deal the cards underhand, stud style）的方式发牌，那么每张牌的牌面就能在到桌上之前，对着观众一小会儿。而且还要让发牌的速度慢下来，好让观众有足够多的时间看清每张牌的牌面。

还有一点，在用纸牌表演时也要非常注意，观众总是对于牌面和牌背更感兴趣，而不是牌边。这就将我们引向了可视性的第二个原则：要把牌面向下倾斜，这样观众才能看到它们。如果你站着表演时，向下倾斜牌面就会显得很自然，但是坐着的时候，就显得有些笨拙了。

多数近景魔术师在表演纸牌魔术的时候，看起来都好像是在为他们自己表演。好像只要他们自己能看清楚究竟发生了什么，这就够了。他们做双翻的时候，拿牌的姿势只能让观众看到前面的牌边。他们在做艾尔姆兹雷数牌的时候，只有自己能看清牌面，而观众也只能看到牌边。

我曾受邀去一个国家的魔术大会比赛上做评委。看到一位年轻的魔术师表演了《牌桌上的达尔文·奥提兹》中的“现代爵士Ace”[^2]这个流程。这个魔术中包含艾尔姆兹雷数牌以及其他手法。在他表演的整个过程中，虽然我坐在比较高的看台上，但依旧只能看到一个牌边。如果这个流程不是我自己发明的，肯定不知道他在表演什么效果。（无论如何我还是在比赛中给了他第一。毕竟他选择流程的用心程度远超其他所有考虑因素。）

问题的关键在于，魔术师们总是假定，如果他们能看清某件东西，那么观众就也能看清。当然，相反的假定也会出现问题。特别是在给一群坐着的观众表演时，你必须意识到后排的观众视角，往往要比正常视角更低一些。这就意味着，如果你不把牌面向下倾斜压低的话，那么观众就有可能看到你手底下的位置或者整叠牌的底牌。

我曾经见过，有魔术师将观众选到的牌控制置底之后，以一种多数人都能看到底牌的姿势来持牌。还有许多次看到他们将四张Ace偷换成K的时候，会以一种观众能够看到牌叠底部是一张K的方式来拿着牌叠。表演者总是以为，只要他自己看不到，那么也就没人能看到。作为魔术师来说，最遗憾的是，当我们在魔术大会或者是讲座中，看到有表演者犯此类错误的时候，也会视而不见。而不是以一种质疑的眼光来审视这些表演，从而从错误中学习。

除了可听性和可视性之外，还有一点在给许多观众表演时也很重要，那就是要与每位观众产生联系。你必须让在场的每个人都感到自己是表演的一部分，不然便会失去他们。他们会开始游离，有可能是身体上的或者至少也是走神儿了。那些还没习惯给很多观众表演的魔术师，有时会将整个表演专注于离他最近的两三位观众，而忽视了其他人的存在。剩下的观众就会觉得自己是在偷听，而不是跟表演者分享魔术的体验。

想要避免此类问题发生，最有效的工具就是眼神接触。你必须不停地看着不同位置的观众，不管他们是坐在近处还是远处。（我强烈建议大家研究一下胡安·塔玛利斯[^3]的《五点》[^4]）想要做到这一点，就必须确保让自己的台词将观众作为一个整体。不要只和参与表演的观众一个人讲话。你必须将自己的注意力分成两部分，一部分给台上参与表演的观众，另一部分给剩下的观众才行。

还有一点尤为重要，我称其为“外围意识”。当一群观众聚在一起，观看一个近景表演的时候，很多人会站在较远的一侧。那么此时，如果表演者没有“外围意识”，就会在不知不觉中只专注于前面的观众，而忽视其他人。记住，一定要与远处的观众有一些互动，还要和他们有眼神的接触才行。

在给很多观众表演时，还有一点很难讲清，就是表演者要让表演本身的“尺寸”更大一点。你必须夸张一些。你的手势动作幅度要大一点，讲话也要更加掷地有声。当然，在给小部分观众表演的时候，也要把表演的“尺寸”再次缩小；否则，你会看起来更加具有戏剧性。积累经验并做出相应的改变，才是其中的要诀。

在正式场合里给很多观众表演时，你可能会想叫上一两个观众作为助手上台帮忙。想要处理好这种情况，本身就是一门学问；我们将会在下一个章节中探讨这个问题。

最后，还有一个要点对于给多数观众表演时也很重要，那就是喝彩的技巧，虽然多数近景魔术师并不是太在意这个问题。这个主题已经巧妙的被亨宁·内尔姆斯的《喝彩及如何获得喝彩》讲义包含其中了。（这本讲义在1978年11月时，再版在了《魔灵》杂志中。）与其在这里将作者的观点简单重述一遍，我还是建议大家自己把它找来看看。

[^1]: 发牌的过程中，把牌翻成正面朝上的状态放在桌上。详见《纸牌大学》第一册（中文版）30页。

[^2]: 现代爵士 Ace（Modern Jazz Aces）。

[^3]: 胡安·塔玛利斯（Juan Tamariz）深受广大魔术师尊敬的西班牙纸牌魔术之神，错误引导领域的专家。

[^4]: 《五点》（The Five Points in Magic）。
