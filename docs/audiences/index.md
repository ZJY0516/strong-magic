# 第十九章 『观众』

我们这些职业魔术师，偶尔也会在观众中碰到业余魔术师。在表演结束后，他们总会来找我们这些专业人士“聊聊天”。但多数职业表演者对此，都会由于各种原因而感到不太愉快。我的原因是这样的。几乎每次我表演完之后，都会有业余爱好者给出这样的评论：“你的观众们真是太好了。”

表面上看起来，我好像得到了很多掌声，很多笑声，观众的反应也很好，而我的技巧也毫无问题。但这不过都是运气好罢了。我只是碰巧遇到了一群“很不错的观众。”所以我怀疑，如果我演的不好，那么这些爱好者们一定会走开，并认为我是一个糟糕的魔术师。他们也不会过来告诉我，我不过是碰巧遇到了一群“很糟糕的观众。”

我之所以提出这个小小的烦恼，只有一个原因，那就是多数魔术师在用完全相反的方式来评价他们自己。如果他们的表演进行得很顺利，那就证明他们自己很优秀。如果他们演砸了，那肯定是因为遇到了一群“很糟糕的观众。”

有些观众的反应确实比另一些要好，而且他们相较另一些观众而言，也更好的做好了让自己被娱乐的准备。尽管如此，观众间的差异也并不是影响你表演好坏最重要的因素。重要的是表演者本身究竟有多优秀。事实上，不同观众之间的相似性，要远大于差异性。

之前已经说过，你越是了解不同种类的观众，就越能知道该如何与他们打交道，这样你才会成为更加优秀的表演者。让我们一起看看主要都有哪些类型的观众吧。
