# 选择助手

我曾经见过一位喜剧杂耍演员在大学里的表演。某一时刻，他选了一位观众上台作为助手。当这位助手在接下来的指令中犯错的时候，这位演员看着观众说到，“这不是他的错。是我的错……因为是我选了他。”很明显，他的意思是，“选了这么个傻瓜上台帮我，绝对是我的错。”

虽然这句话把观众逗笑了，但是我不建议大家使用这种带有侮辱性质的幽默。尽管如此，杂耍演员的这句话，还是值得每一位魔术师反思的。所有你表演中出现的问题，都是你的问题。其中包括了由助手的行为造成的问题，因为是你把他或者她叫上台帮忙的。这里有一些我觉得有用的诀窍，可以帮你避免挑到扫兴鬼和找麻烦的助手。

在我开始挑选助手之前，会先“扫描”一下观众，特别是女性观众。虽然我很小心的不盯着某个人看，但实则会在心里小心的把想选的观众记下来。我会找那些正在笑，脸上还满怀期待表情的人，就好像她们很期待这场秀一样。然后立即排除那些一脸无聊，或者专注于小声谈话的人。不用说，那些看上去喝多的观众也不行。

有时候当我看着一位观众时，她会对着我笑。任何时候发生这种情况，就表示她会成为助手的人选。这里面绝对没有任何打情骂俏的动机。只能说，按照我的经验而言，这种观众比较完美。不管怎样，至少对我是如此。

在我的许多表演中，都会有人在表演开始时对我进行介绍。并不是每一个近景表演者都有这样的优势。然而，任何时候有这种机会出现时，都会对你选择助手提供帮助。当主持人介绍我的时候，我就站在一边，然后看着观众。他们听介绍有多认真，就有多期待你的表演。

时常我会发现，有女观众在主持人介绍我的时候，将目光在我和主持人之间切换。她听到的内容，让她对我产生了好奇，于是才要仔细看看我。就像我之前说的，先有眼神接触，然后微笑，这便是我寻找理想助手的信号。

在有许多近景表演的情况下，你需要一晚做好几场表演。这种情况时常出现在我的表演当中。当然，这也为选择一个理想的助手打下了基础。因为你的表演会有许多的“回头客”。（如果没有的话，就重新阅读一下本书前面的章节。）

当你看到一位出现在之前表演中的观众时，你就知道她喜欢你的表演。而且，因为你之前就观察过她，所以知道她的表现力究竟如何。如果一位观众反应很好，而且是你的“回头客”，那么她也一定会很好的配合你。她便会成为你接下来表演中最理想的助手。

在一些表演情况下，你可能会在一开始，做一些需要走动的魔术表演，接着再来一场需要坐下来的表演收尾。原理还是一样的。在你走动表演时反应很好的观众，也会成为你坐下表演（正式表演）时最理想的助手。

如果你的表演经验不是很丰富，可能会觉得很难记得上一场表演时观众的脸。但是对于任何经验丰富的近景表演者来说，在场每位观众的面孔都是刻在他们心里的。（如果你不是这样，证明你的魔术练的还不够好。你还在专注于自己必须对旁边观众说或者是做的事情。）确实，我会时常在表演中记住一位反应很好的女观众，然后选择她作为之后表演中的助手。

关于需要避免选择什么样的观众做助手，我还想再说一点。除了很明显的喝醉、面无表情、百无聊赖以及专心和邻座说话的人之外，还要避免任何非常渴望被选上台来做助手的观众。她们想上来，只不过是想成为表演的中心，展示自己而已。但你才是整场表演中的核心。所以千万别把表现力和爱显摆搞混。除非你想和一个以自我为中心的人同台竞技，不然就别选那些死去活来都要上台的人。
