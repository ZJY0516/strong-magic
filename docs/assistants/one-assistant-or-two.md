# 选一个助手，还是两个？

在正式的近景魔术秀中，我建议大家最好请上两位助手，而不是一位。因为这能有如下几个优势。首先，如果你只请一位观众上台，那么她会显得比较拘谨，因为她觉得每个人每时每刻都在盯着她。这种自我意识会对观众的表现力产生影响，从而对你的表演不利。但如果你请两位观众上台，那就不一样了，会将这种无形的压力分开。她们都会觉得很放松，并且更容易自发的对你的表演做出比较明显的反应。

其次，当你请两位观众上台的时候，表演中的互动会更具娱乐性。其中包括她们感到不可思议的样子，以及惊讶疑惑的表情，或者是其中一位问另一位观众，这一切是如何发生的。台下的观众会觉得这样更有趣。同时也能向剩下的观众强调，你的表演究竟是多么的不可思议。

再次，当你请两位观众上台的时候，便相当于为自己准备了一条退路，万一其中一位观众非常不配合的话，至少还能用另一位做补救。你可以让更配合的观众，来参与效果中所有需要观众参与的部分，同时无形中将找茬的那位晾在一边。

尽管如此，你还是应该在真的需要两位观众配合的时候，再请上两个人。毕竟把其中一个晾在一边肯定是不好的。这就为什么我要在自己的七场近景表演中，只有一场请上了一位观众的原因。所以在这场表演中，我选助手的时候总是非常慎重。
