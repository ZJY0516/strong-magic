# 选择谁？

因为选择助手对表演的成功而言十分重要，所以一定不能失去做选择的权利。通常你都会叫一位观众上台，不管是谁最先上来，就选他了事。（但事实上，像我们之后会看到的，其实愿意上台作为助手的观众，往往并不合适。）

在表演前，可能会有人提出，让你选他的女朋友，或者其他人来配合你的表演，这也是平常会遇到的情况。他很可能会向你保证，她绝对是一个“完美”的助手，但是因为他并不知道表演中具体要做什么，所以任何保证其实都毫无意义。

有时你还会遇到，所有观众都围坐在一个大桌子上的情况。如果你只是告诉他们要把位子坐满，那很有可能到时候就只能选择离你最近的观众作为助手了。不然，就把你的包或者其他一些道具，放在你想让助手坐的椅子上。当然也可以在椅子上挂一个“已预定”的标志。（你可以在飞机上偷一些“已占用”的多语言标签。）当你开始表演时，再把放在椅子上的道具拿开，然后选两位符合上述条件的观众，邀请她们坐在你的身边，协助你的表演。
