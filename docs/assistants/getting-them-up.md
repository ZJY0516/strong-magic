# 让观众上来

几周之前，我参加了一位大咖的魔术讲座。他的多数流程，都需要观众配合。每次出现此类效果的时候，他都会看着观众，然后问，“我能请一位观众上来做助手吗？”

当表演者提出这样的要求时，通常都会得到这样的回复：没有回应。每位观众都安静而紧张的坐在那里，等待着有人上去做表演者的助手。在这没完没了的等待当中，表演者什么也没说，什么也没做，就盯着观众看。

最后，终于有人受不了这种让人难受的寂静，走上前去。在效果结束后，表演者就会让助手下去。等下一个需要观众配合的流程出现时，再重复上述过程。这种让人沉闷的重复，大约会在整个讲座中发生六次。

这个表演者最明显的错误，就是不停地在每个需要观众配合的效果结束后，就让她们回去。一旦你找到了合适的助手，就要一直把她留下来。并不是非得需要在每个效果中都给她们找事儿做。她们只要坐在那里，就能看，也能有所反应。他的第二个错误，之前我们已经说过了。如果随便让一位观众上来，就相当于放弃了选择完美助手的机会。

这个故事也说明一个问题，如果你不知道如何请观众上台，那么便会在一开始就打乱表演的节奏。一旦你决定选择某位观众作为助手，就要看着她，指着她，问她是否愿意上台来帮助你。她可能并没有立刻意识到你在跟她讲话。如果是这样的话，便可对她的穿着进行一下描述，“那位穿红裙子的女士，愿意上台来帮助我吗？”

偶尔，观众会拒绝你。她可能会摇摇头，然后说，“请选别人吧。”我基于长期总结的经验是：别选其他人。然后坚持以一种友好，和善但决不妥协的方式，继续邀请她。她会上来的，而且几乎不会拖延。这是由于巨大的压力产生的。她意识到每个人都在等她，所以才会上去。（这里又要引用一下之前魔术讲座的例子了。每个人都在等待表演开始，所以对于等待都会觉得不适。但此时并没有一个人觉得是自己造成的，所以才没人上来。）

当遇到特别不情愿上来的观众时，我会说，“我保证你会喜欢的。只要上来一小会儿就好，如果你不喜欢的话，可以马上回去。”从来没有人在我说出这句话之后，再次拒绝我，也没有人在表演结束之前要求回到自己的座位。只要你自己足够坚定，她就会上来。而且，你了解自己的表演，很快她就会很开心的。

我知道，肯定有人会质疑我提出的这些建议，所以请允许我解释一下其中的缘由。首先，你可能认为，如果一个观众不想上来的话，那么她就不会是一个好助手。我想再次提醒大家，不要把表现力和爱显摆搞混了。一个爱显摆的观众，上台之后总想让其他观众注意自己，而不是你。一个比较矜持的观众可能会不愿意上来。但是一旦她上来了，就会很配合。而且，如果你让她安心的话，她也会更放得开，更具表现力。那些最初不情愿上台当助手的观众，多数都与我一起度过了一段美好的时光。她们也总会在表演结束后，感谢我让她们上台协助表演。

那么，让我们试想一下另一种情况。你让一位观众上台做助手。因为她拒绝了，所以你选了别人。我相信我能预言出接下来会发生什么情况。第二位观众也会拒绝。下一位还是如此。只要她们发现可以说不，那么每个人都会说不。所以最好花些时间在第一位观众身上，总比花半小时一个个去求观众要强。

只要有经验，你就知道谁是最适合作为助手的观众。一旦你做好了决定，就不要接受否定的回答。她们之所以不情愿的理由，无非是不知道会体验到多么美好的东西。而你知道，所以要帮助她们，坚持一下。这也是为了她们好。
