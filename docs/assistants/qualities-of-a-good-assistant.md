# 一位好助手的品质

你想请什么类型的观众上台来做助手呢？需要寻找有两种决定性品质的人：会表现的（表现力）和乐意配合的（协作性）。表现力的重要性，我目前为止已经讲的很清楚了。协作性的价值不言而喻。你肯定不想找一个处处和你唱反调的观众上台来作为助手。有了经验之后，即使是最难缠的观众，对你来说也不在话下。然而，如果你的助手很配合，而不是个“刺儿头”的话，肯定能让整个表演更加精彩，这个事实是不会改变的。此外，这两个品质又是有联系的。一个不肯配合的助手，肯定会尽他所能，对你的表演显得毫无反应。

当我做千术表演的时候，通常都会选择两位男性观众作为助手。之所以这样，首先是因为我想创造出一个比较地道的赌博场景；在我们的文化中，通常是男人和男人玩牌，女人和女人玩牌。其次，因为我打算在表演的时候，不断地“刺激”一下这两位观众，所以我不想让大家觉得我在欺负一个弱女子。所以我选了两个男人，因为他们看上去能够照顾好自己，而且不需要广大观众的同情。

然而，当我表演近景魔术的时候，总会选择女观众上台作助手。首先，女性观众很少会与男性表演者产生竞争或者对立的态度。（“如果你骗了我，我就输了；如果我抓住你，我就赢了。”）其次，女性观众更容易公开地表现出对于表演者和魔术本身的赞赏。（请注意，以上两点的前提，都是建立在表演者为男性的基础上。虽然我不能凭经验说话，但是我发现如果表演者是女性时，情况可能会有所不同。）再次，在我们这个社会中，女性更加倾向于可以自发的、自由地表达自己的情感。如果有一位男士打开自己的手掌之后，发现里面本该是一个的海绵球，竟然变成了两个！此刻他也许会像女士一样惊讶，但基本不会把这种情绪用尖叫声表达出来。

在选择助手的时候，我总是会找那些比较具有吸引力的女士，因为对于表演的艺术感染力而言，这是一种非常合理的考虑。当然我必须强调一下，外表的吸引力并不是最重要的考虑因素。有些魔术师在选助手的时候，搞得就像一场私人选美比赛一样。表现力与协作性，绝对比美貌更重要。

事实上，我相信如果女观众太惊艳的话，反而对表演不利。我在看近景表演时，曾经不止一次的因女助手美丽的外貌，或者是她的乳沟而不断地分心。于是我想，既然这样会让我分心，那么当我表演时，也一定会让我的观众们分心。在一大群典型的观众中，肯定会有很多具有吸引力的女观众，可以请上台当作助手。这能让你在做出选择的时候，基于更加重要的标准。
