# 助手的重要性

当为很多观众表演的时候，表演者叫上一两位观众上台协助，就显得十分常见了。这些协助表演的观众，也会在成功的表演中扮演尤为重要的角色。首先，这些作为助手的观众，能够帮助台下的观众确认魔术的欺骗性。当观众人数众多的时候，有些坐在后排的观众就会完全被蒙到，然而他却更想知道，自己之所以看不出魔术的秘密，是不是因为距离太远造成的，是不是只要他坐得近一些，就能“抓住”你。但是当他看到，坐在你身边的观众同样被蒙到的时候，就会意识到这与距离没有关系。

其次，作为助手参与表演的观众，能为剩下的观众提供一种间接参与表演的感觉。当然，最理想的状态，是让每位观众都能在某一时刻参与进表演当中。当为少数观众表演的时候，你时常都能达到这种状态；然而，一旦观众人数一多，就显得很不实际了。这便是台上作为助手的观众所发挥的作用。因为她来自观众，所以他们会将她作为代表；认可她，由此来获得参与表演的感觉。

第三，台上作为助手的观众，能够成为表演中台下观众反应的催化剂，这一点非常重要。时常一个来自台上助手的强烈反应，会下意识的为台下观众做出相同的反应提供一个线索。台下的观众会模仿他们从她脸上看到的不可思议的表情，或者是喜悦。（这便是我们之前讨论过的，关于暗示的一种特殊应用。）这就是为什么，你一定要寻找一位性格外向的观众做助手，而不是一个压抑甚至隐藏自己情绪的观众。就像约翰·布斯[^1]博士在他的《戏剧性魔术》[^2]一书中说的那样，“情绪产生情绪。”

最后，台上观众本身对于各种效果的反应，也为台下观众提供了快乐的源泉。毕竟观众自发的情绪更有说服力。这也是为什么我们在电视新闻中看到灾难受害者的情绪波动之后，会为他们遭受的不幸而感到惋惜。

另一方面，电视游戏节目的胜利者跳跃着，喊叫着，也能为节目带来更多的娱乐价值。游戏节目的制作人就非常清楚这一因素的重要性，所以他会面试这些可能参赛的人，寻找那些富有表现力的参赛者，而不是那种看上去缺少情绪反应的人。另外，这些游戏节目的参赛者，时常会在节目开始前就得到提示，如果他们得奖的话，要如何表现出兴奋和激动的样子。

想想Slydini“飞过头顶的纸球”流程，就会发现它几乎全是依靠台下观众对台上观众的情绪反应来产生娱乐价值的。我曾见过一位表演者，因为不幸的选择了一位比较木讷的观众上台来做助手，而让这个效果的冲击力大大减弱，台下观众的反应也大不如前。

[^1]: 约翰·布斯博士（Dr. John Booth），美国职业魔术师及魔术表演历史方面的高产作家。
[^2]: 《戏剧性魔术》（Dramatic Magic），约翰·布斯博士1988年的作品。
