# 欲望

> “我们更容易去相信那些我们所希望的。”
>
> ——狄摩西尼

在童话故事《皇帝的新衣》中，骗子告诉大家只有聪明人才能看到那新的皇家服装。因为每个人都希望自己聪明，所以每个人都想要看到那些衣服。如果看到了衣服就证明自己是聪明的。事实上，这就是有效暗示的最重要的关键所在。人们趋向于看到他们想要看到的事物，体验他们想要体验的事物。这就是为什么某些庸医却很成功。他们那些绝望的患者，期望存在某些奇迹般的治疗，让他们免于死亡。这也就是为什么灵媒借用最原始的方法也能够成功地欺骗那些无知的人们。那些人们因为失去亲人而悲痛万分，他们内心渴望去相信，希望挚爱并不是永远的离他们而去。

我们魔术师们可以利用这个因素，通过选择不同的魔术主题去迎合观众们内心的欲望。这样可以使得观众们更容易进入魔术幻觉之中。有关这一点，在之后章节讨论实质性含义时会显得更加清晰明确。

就现在而言，我先举个反例，千万别这么做。有个古老的纸牌魔术叫做“IQ 测试”。意思是，如果观众在特定时刻没能搞清楚那几张牌在哪里的话，我们说他可能脑残了。这算不上一个使观众想要被愚弄的魔术主题。你就想象一下，如果皇帝的裁缝，告诉大家只有愚蠢的人才能看见皇帝的新衣的话，那么这个骗局还有没有可能成功呢？

另外一种利用欲望来暗示的方式是，表演时与观众建立一种深厚的关联。有句古话叫：如果观众喜欢你，那么他们也会喜欢你的魔术。如果观众喜欢你，也许他们只是在你魔术表演得糟糕时，会更加尴尬一些。如果真是这样，那就是说，如果观众喜欢你，那么他们会希望自己能喜欢上你的魔术。他们自己会潜意识地更加乐意接受你创造的幻觉。

举个例子，我发现如果我已经建立起足够的威信和观众有良好的关系，他们就会拒绝相信我也会出错。如果有些不太对劲的地方，只要我能够半路想出个解决办法处理好，他们会高兴地相信那是事先预备的表演中的一部分。
