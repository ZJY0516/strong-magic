# 负面暗示

理解暗示的作用很重要，暗示不仅仅可以加强你的魔术效果，而且可以保证你不会在无意间用暗示削弱了你的魔术效果。魔术师们通常会对自己的魔术发表一些即兴评论，有时候反而害了他的魔术表演。经典的例子是，魔术表演者说：“我这儿有个普通的，事先没有做过任何手脚的酒杯。”在他说这句话之前，观众们从来没想过那个酒杯还可以用特殊的方法做什么手脚。但是魔术师说了这句话，观众们就开始有这个想法了。

我有次看到一个魔术师给一个女士表演几个神奇硬币魔术。随着逐渐崇拜的心情，女士说：“你一定花费了大量的时间去练习吧。”他却回答说：“其实我几乎没有练习过。”

在他说完这句话的时候，我看到女士脸上所有的热情都退却了。他当时没有意识到这一点，继续他的表演。他同样没有注意到的是，这名观众对他之后的魔术几乎就再也没有反应了。他很随意的，考虑不周的一句回答，其实表达了这样的暗示：我给你表演的魔术没什么了不起。而她之后对魔术师的表演也就是这种感受。

在观众面前，几乎你所说所做的一切，都会在表面文字之下包含其他的讯息。你一定要确保那些讯息能够用来创造他们心中你所想要的期望。
