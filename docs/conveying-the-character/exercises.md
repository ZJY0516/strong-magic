# 练习

> “一般而言，人们的判断更注重于外表而非本质。”
>
> ——马基雅弗利，《君主论》[^1]

在这整篇章节中，对于如何使用这些技巧帮助你演绎传达你的角色，我提出了很多实实在在的建议。我想在这一章结束的时候，提供给你一些练习以保证你可以更深入地理解本章的内容。

在给观众传递你的角色上，有两个清单可以给你巨大的帮助，我们将其称为角色材料清单。对于第一个清单，应该以你在上一章中列出的角色档案开头，在这之下列五栏，标题为：穿着，用词，角色经典台词，效果和道具。

在“穿着”这一栏，列出在你演出时，你认为对传达你的角色特别有帮助的服装。这或许会包含一件特殊的T恤，领带，或是夹克。它之所以重要或许是因为它的风格，设计或是品质，它或许还包含珠宝或是其他的装饰物。在“用词”这一栏，列出你台词中适合我们上述讨论的理由的单词或是词语。在“角色经典台词”这一栏列出在前文中我们讨论过的适合你的经典台词。在“效果”这一栏列出那些在你的演出中特别适合你的角色的效果，或是那些帮助你定义你的角色的效果。在“道具”这一栏列出在一个效果中你用到的每一个和你角色相匹配的道具。

现在研究结果，这张清单会帮助你找到你薄弱的区域，或是为了传达你的角色而应该更加充分开发利用的区域。

第二张清单的结构与第一张完全一致。然而，在这张清单中你列出的不是你现在穿的、说的、做的或是用的。你列出的是你可以想到的，所有能帮助你关联你的角色的穿的、说的、做的或是用的。

你或许可以列出那些价钱合适时你想买的配件、一个效果需要使用的道具、你会用到的角色台词（如果你可以找到合适的情景）。

在“效果”这一栏不要列出具体的效果，而是列出日后能成为某一个效果的主题。如果你是一位心灵魔术师，你或许应该列出“心灵燃烧转化（psychokinetic combustion）”。如果你是一位超能力者，你或许应该列出“萨泰里阿教（古巴一宗教）”。如果你是一位老千，你或许应该列出“在巴卡拉游戏中出千”。如果你的角色是一个骗子，你或许应该列出“少换零钱（shortchanging）”。

时常回顾第二张清单。它会帮助你找到合适你的新的材料。如果没有这张清单的话，你会很容易忽视一个很适合你的效果或是忽视将一个效果修改成适合你的角色的方法。同样的，如果你有新的想法的话增加到你的清单之中。

同时我也建议你学习一些讲印象操纵的好书。印象操纵是心理学家用来描述那些控制他人对我们所产生的印象的技术。像《成功衣着（Dress for Success）》这样的好书，我要特别推荐的是由大卫·路易斯（David Lewis）写的《成功的秘密语言（The Secret Language of Success）》和艾森（Eisen）和法利（Farley）写的《强势说话！（Powertalk！）》（第二本书会让你很好地意识到怎样通过措辞和选择词语来改变观众对你的角色的印象）。那些讲穿着的，身体语言的和其他不用语言交流的书都会帮助你发现我们是通过什么来给别人下定结论的。

在这一方面，一个很棒的练习是观察其他表演者，不论他们是魔术师，喜剧演员，歌手或是音乐家，在这之后思考你觉得他们是哪一类人。然后回想是哪些因素使你得出了这些结论。毕竟，你并不认识这些人，你只是在基于观看他们几分钟之后就得出了结论。你也可以对你日常接触的人做同样的事情。这一练习会帮助你对他人发出的微妙信息反应，由潜意识层面提升到有意识层面，反过来就会帮助你运用这些信息来控制他人看待你的方式。

[^1]: 马基雅弗利（Machiavelli），意大利新兴资产阶级思想政治家，历史学家。《君主论》（意大利语：Il Principe）是意大利文艺复兴时期马基雅弗利的政治论著，1513年献给洛伦佐二世·德·美第奇，但此书在马基雅弗利死后才出版。
