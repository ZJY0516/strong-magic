# 你该穿什么

> “带有帽中兔图案的领带夹和袖扣坚决不能穿，M型戒指同样应该避免。我不想吐槽那些上面有纸牌或是兔子图案的领带，对于真正的纸牌魔术师而言，这些根本就不需要我去提醒。”
>
> ——大卫·本迪克斯[^1]

很多关于魔术演技的书内都充斥着时尚、打扮、和个人卫生的建议。我并不否认它们的重要性，但是你可以走进任何一家书店，并且找到一堆由专家写的关于这方面的好书，所以我为什么要假装是你的时尚顾问？与之相代替的，我想帮你分析，你的外貌是如何影响观众看待你的角色的，从而，影响他们看待你的魔术。

在这个国家骗子盛行的鼎盛时期，职业的骗子通常会见到一些有钱的富商并且在几个小时之后，成功地赢得他们的信任，在无任何抵押品的情况之下将一大笔钱转入他们的账户。这些受过良好教育的聪明商人愿意去相信一位从未见过的陌生人，因为骗子可以仅仅通过他们的穿着、装饰和行为举止让受害人相信他们是同一类人，因此是可以相信的。这些骗子知道所有的人都会仅仅通过他们所看到的就对他人做出坚定的判断。

当一个人第一次看到你时，通常会在以下方面对你得出结论：你是保守还是豪放，害羞还是开朗，你的经济地位，出生背景，社会地位，个人癖好和其他个性，甚至你一个字都还没说。因此，你的外貌是你将你的角色传达给观众的首次机会，这意味着你的戏服必须要能反映出你的角色。

是不是“戏服”这个词震惊到你了？很多近景魔术师认为戏服是舞台魔术师才需要考虑的事情。如果你是一名近景魔术师，你或许认为你从未穿着戏服表演过。再仔细想想，除非你全裸表演——如果你在这样思考的话，即使你真的全裸了——你还是穿着服装在表演。

戏服仅仅是魔术师特别选择，用来给观众留下特别印象的衣服。然而，不论你穿什么在表演时你都会留给观众某种印象，不论你是否用心去挑选过。因此，在表演时不论你穿什么它都是你的戏服。

重要的是你的服装不能传递给观众那些有损你试着去建立的角色的信息。这意味着你必须问你自己，我的角色适合哪种衣服，珠宝和配件？然后整理出一身行头。

在这一点上，我想我有必要提醒你一下。你的外貌必须传达你的角色。但是就我们讨论的这一章的所有内容而言，考虑的关键是可信度。你的服装太过于夸张是有危险的，穿着穆斯林头巾和长袍并不是最好的传达你是一位神秘的魔术师，就像穿的像十九世纪游艇上的花花公子，并不是最好的传达你是一位老千一样。这样的想法只会让你的观众认为你是一个刻板的模仿者，而不是一位天才的艺术家。

为了成功地搭出一身可以很好地传达你角色的行头，你必须有一种人们对于不同的外貌有着怎样不同反应的感觉。一个很好的练习是观看其他的表演者，并且问你自己：他们的外貌传达给了观众什么样的信息？如果你坐火车上班，那么试着扮演福尔摩斯来观察其他的乘客，从他们的服装和装饰上推断出关于他们的每一条信息。

你的结论对或错都没有关系。在这些练习中，你有意识地得出的推论，和你的观众在看你时无意识地得出的推论是一样的。没错，这就是那种在日常人与人的互动中，无意识地得出的结论。这些练习的作用是帮助你将这一问题，上升到形成一个结论的高度，所以你可以用它来影响你的观众。

我建议你找到约翰·莫洛伊（John Molloy）的经典之作《成功衣着（Dress for Success）》并仔细地研究它。我并不是让你接受他的每一条建议，而是学习他的思想。莫洛伊的建议是让你看起来像是企业高管，除非它就是你想要传达的角色（它可以是，如果你想要专门从事展会工作），否则没有理由采纳他的所有建议。还有很多讲穿着的书教你如何将自己打扮的像是商业精英。莫洛伊的书内精髓，在于他深深地知道怎样利用穿着和装饰在心理上操纵他人，就像早年间的骗子一样。这是你应该学习并应用到魔术上的东西。

当然，如果你不是职业魔术师的话，你的服装通常是当你有机会变魔术时恰好穿着的衣服。但它仍然是你的戏服，这只意味着你衣柜里的每一件衣服都要符合你的角色。

这并不意味着你必须烧掉衣柜里的所有衣服，并买新的衣服让你所有的朋友都不认识你，如果真是这样，你选择的角色与你真实的自己相差太远了。我的意思是在你购买衣服时，全方位地考虑你的角色特征，购买那些可以突出这些特征的服饰。

[^1]: 大卫·本迪克斯（David Bendix），Bendix Bombshell Wallet 的发明者，改良了很多魔术效果。
