# 主旨

主旨不应该与主题混淆。当你使用一个主题的时候，它应该贯穿于每个效果当中。它就像一条线，可以把单独的部分都串在一起。就算只有一个效果与主题不一致，整个表演也都会跟着遭殃。而主旨并不是贯穿于整个表演里的东西；而是会周期性的出现在表演中。表演者甚至可以演上一个或者是几个并不包含主旨的效果，但他会在表演中经常触及主旨，并使整个表演具有连续性和统一性。

近景表演中最出名的主旨之一，便是阿尔·高斯曼[^1]那套从物品下面变出硬币的表演。“盐瓶下的硬币”并不仅仅是高斯曼表演的招牌效果之一，他还会一次又一次地，从其他效果所用的道具下面把硬币变出来。就像魔术中其他伟大的艺术处理一样，高斯曼是有意将这个效果作为主旨来应用他的表演中的，这一点在《高斯曼的魔术》[^2]一书中，就有详细探讨。

另一个非常依靠主旨在经典近景魔术表演中发挥作用的例子便是德尔·雷[^3]。他表演中的一个主旨，便是用50美金的纸币来进行挑战，如果效果失败，那么钱就归观众。这种策略被许多魔术师应用在单一的魔术中，但德尔·雷却将它一直作为一个幽默的来源，并以此来强调自己的表演有多么的不可能。他会与观众进行一些纸牌游戏，并拿出50美金给最后的赢家。最后，他还会与观众玩“二十一点”，再次拿出50美金给拿到最好牌的人。同样，在他和观众玩骰子的时候，还是会拿出50美金。

德尔·雷并没有仅仅局限在赌博效果之中，实际上他几乎把这50美金与每种效果都结合了起来，比如找牌、预言，甚至是转移效果（他有个自己版本的“弗农的挑战”[^4]）都有。某些时候，他也会稍微改变一下套路。比如他会提出，要是有一个效果表演失败了，那么他就把自己的机械鸟送给观众。

德尔·雷并不会在每个效果里都提出这样的赌注；因为他知道，想要保持对观众的影响，任何方法都要用之有度。同样，赌注本身也决不是他表演的理由。因此，这不是一个主题，而是一个真正的主旨，他既独特又魅力十足的个性，也会让他的表演变成一场既完整又让人印象深刻的奇妙体验。

在一场表演中，只能有一个主题，却可以有好几个主旨，这便是主题与主旨最大的不同。德尔·雷的表演，再次为我们提供了一个范例。除了提供现金奖励之外，他的表演中还有另外一个主旨，就是那种看起来有生命的玩具动物。他的表演会以一只跳出来的玩具兔子开场，并用一只找到观众所选牌的老鼠结束。在表演的过程中，我们还能遇到一只会翻跟头的青蛙和一只能够预言未来的机械鸟。在整个表演过程中，德尔·雷会把它们当作真的动物对待，而且它们的反应似乎也证明他是对的。这些玩具动物，并不会出现在德尔·雷表演的每个效果中。相反，它们只是偶尔出现，从而为表演提供一个统一的主旨。

我自己的作品也能很好地说明主题与主旨的不同。就像我之前讲过的，在我的千术揭秘表演中，不正当赌博便是主题。但是，在我的近景纸牌表演中，千术就不是主题了，因为我的表演是以纸牌魔术为主导的，而且观众会意识到这个表演的目的只是为了娱乐他们，而不是像千术揭秘的表演中那样做“科普”。但无论如何，在近景魔术表演中，我依旧会把千术作为一个主旨。千术流程还可以作为“点缀”，出现在比较直接的魔术效果中。至于千术术语和参考资料什么的，就有很多了。

甚至有几个很直接的纸牌效果，在表演方式上也会涉及一些和千术有关的话题。例如，这里有两个来自《牌桌上的达尔文·奥提兹》[^5]里的例子。“达尔文的疯狂变牌”[^6]便是一个用点数为2的牌表演的效果，他会向观众解释，为什么“2”会被当作扑克牌中很疯狂的一张。“幸运扑克”[^7]则是一个将牌面印在一副空白牌上的效果。表演者会告诉观众，这副牌原来属于一位技术一流的赌徒——他的祖父。他说这副牌会带给他好运，而且已经用了好久，所以最后连牌面都被磨掉了。因此，我们便使用了各种各样的方法，来强调扑克牌作为千术工具的基本功能，从而为表演提供了一个统一的元素来作为主旨。

[^1]: 阿尔伯特·高斯曼（Albert Goshman，1920-1991），布鲁克林出身的近景魔术师，以“硬币与盐瓶”流程闻名。

[^2]: 《高斯曼的魔术》（Magic by Gosh）。

[^3]: 德尔·雷（Del Ray），他以擅长在表演中使用电子设备而闻名。其生平及故事详见《Del Ray: America's Foremost》。

[^4]: 弗农的挑战（Vernon's Challenge）。

[^5]: 《牌桌上的达尔文·奥提兹》（Darwin Ortiz at the Card Table）（1988）。

[^6]: 达尔文的疯狂变牌（Darwin's Wild Card）。

[^7]: 幸运扑克（The Lucky Deck）。
