# 第十三章 『多样性』

虽然统一性对于任何成功的表演而言都十分重要，但千万别把它与同一性搞混了。统一性创造的是艺术效果；而同一性只会让人感到无聊。一些人就魔术表演中多样性的重要性，发表了自己的见解。想要在魔术表演中实现多样性其实很简单。但是想在实现多样性的同时又不牺牲统一性，就是另一回事了。

想要编排出一场优秀表演的最大挑战，便是如何平衡统一性和多样性。因为统一性与多样性之间的矛盾，恰好就是一场好表演的力量源泉之一。事实上，在我们之前探讨过的每一个统一性的因素中，都为多样性留下了很大的空间。让我们思考一下下面的这些例子吧。

## 主题

打个比方吧，就算你表演的主题是心灵，也依旧有很多可能性值得探索。你可以表演一个从某位观众那里接收到一个想法的效果；一个将想法传送给某位观众的效果；一个预言效果；以及一个“千里眼”效果。很多年前，尤里·盖勒就帮了心灵师们很大的一个忙，他告诉观众们，很多物理现象，其实都是心灵力量的体现。因此，现在的心灵师们，才得以在自己的表演中加入许多不同种类的效果，从而展示自己是如何通过心灵的力量，来移动或者说从物理角度对物体产生影响的。这些效果，每一个都可以作为从“大主题”中分流出来的一个“小主题”。

许多魔术师在编排一场千术表演的时候，多数都会用一系列的发牌来结尾。其实就不正当赌博这个主题而言，你还能做到更多。你可以演一个用纸牌作弊的效果；一个在“二十一点”里作弊的效果；一个在“金拉米[^1]”或者桥牌游戏中作弊的效果，所有这些纸牌游戏都很流行。你还可以向观众展示，老千是如何用假发牌、假洗牌以及掌藏和换牌手法来骗人的。你可以用一个“三公”效果来做演示，或者展示如何切出 Ace，以及和一位或者多位观众来玩牌，然后在各种不可能的条件下取胜。

还有一种实现表演多样性的方法，就是改变一下你主题的基调。近几年来，心灵师们展示出了他们对于幽默暗示在效果中的强烈兴趣。同样，在千术表演中，你也可以先非常严肃地展示一些被“严格保密”的千术技巧。而下一个效果，又可以表演一个带有强烈喜剧元素的“三个桃壳”流程。

## 道具

大卫·罗斯完全靠硬币就能编排一场表演——确实，完全靠半美金和便士就足够了。但是，他通过引入各种各样的辅助道具，极大的丰富了表演的多样性，而且让观众忽略了这样一个事实：他们不仅一遍又一遍地看着相同道具表演的魔术，而且还一遍又一遍地看着几个相同的效果（消失，出现，转移）。使用钱包框、衣服洞、音叉、杯子、黄铜钱盒、塑料彩虹和金罐都能大大增加表演的多样性，同时核心道具——硬币，又可以很好地确保表演的统一性。

在所有的纸牌表演中，你可以用一整副牌表演一个效果；用一小叠牌表演另一个效果；或者放几张牌在桌上（比如，“疯狂的变牌”或者 Ace 集合这种）；而像“时空隧道（Card Warp）”这样的效果只会用到两张牌，还有一个或者更多效果能让牌叠本身发生变化（比如某个版本的“变色扑克牌（The Color Changing Deck）”，“全背牌”，“微观宏观（Micro Macro）”，或者我自己的“幸运扑克”效果——将牌面印在一副空白的牌上）。这样你便可在保持视觉多样性的时候，又不会违背“单一道具”的概念了。

## 戏剧结构

戏剧结构也许是给表演注入多样性最重要的部分。比如表演一些不同长度的魔术就很有帮助。把一两个长魔术，一两个短魔术，与一两个中等长段的魔术结合在一起，便能给观众一种耳目一新的感觉。

我之前谈到的表演太多魔术的危害，主要取决于惊喜对观众的影响。而你要实现表演中多样性的方式，则是通过把一些能制造惊喜和一些能制造悬念的魔术结合起来实现的。同样，你也可以把一些只有单一高潮和一些有多重高潮的效果结合起来。

运用上述这些各种各样的方法，你便能将多样性融入，即使是看似最完整和统一的表演当中。就像你通过选择效果来实现表演的统一性一样，你也需要通过选择方法来创造表演的多样性，而这一切艺术上的决策权，都只能由你来做。实现这两种元素的平衡是非常必要的。理解这些方法的可能性，其实是一个技术问题。而决定如何去做，又取决于你的艺术眼光，至于最后的结果如何，只能取决于你自己。

[^1]: 金拉米（Gin Rummy）：一个在 1909 年由 Elwood T. Baker 和他的儿子 C. Graham Baker 一起发明的纸牌游戏。
